## ✨ 核心特性

### 🎨 AI 漫画（Comic）
- **参考图角色一致性**：角色参考图锚定跨格统一（角色 LoRA 当前接入漫剧关键帧链；漫画分格链接入见未完成清单）
- **四视图生成**：角色设定图一键出三视图/四视图
- **AI 写分格**：从剧本文本自动划分漫画格（2/4/6/8/12 格可选）
- **台词气泡五形**：💬对话 / 🎬旁白 / 💭思考 / 💥喊叫 / 🤫低语 五种形状一键切换，拖拽定位 + 把手拉伸宽度，导出成册同步烘入
- **资产库**：角色 / 场景 / 道具三页签，支持上传与 AI 生成、批量删除、SAM AI 抠图
- **大图预览**：分格图与资产卡单击放大灯箱、右击直接下载原图
- **整页导出与阅读预览**：PNG 长图 / PDF 每格一页 / PDF 2×2 拼版

### 🎬 AI 漫剧（Manga）
- **分镜编辑器**：剧情 → 分镜 → 资产 → 关键帧 → 视频 → 成片全链路，五步工序条实时联动
- **多角色一致性**：跨镜形象统一（双硬锁并发保护 + 角色 LoRA 身份锁）
- **上游变更过期标记**：改描述词 / 换画风 / 更新资产后，受影响的旧图自动亮「已过期」角标，一键批量重生成
- **视频生成**：主力 MiniMax H3 多镜链式生成（本地 ComfyUI 推理），Wan2.2-ti2v-5b 图生视频补档；视频队列排队/取消/进度可视
- **生成记录**：图片与视频双页签，成功/失败/耗时/模型/seed 全字段留痕，失败一键重试
- **镜头语言结构化**：A/B/C 三段式提示词 + 中文导演运镜 + 台词行 + AI 提示词自定义注入
- **风格包**：30 个预置视频/画风风格包，一键套用，自定义风格包导入
- **资产库管理**：角色、场景、道具系统化管理（描述词生成/AI 抠图/音色绑定/转全局跨项目复用）

### 💬 AI 对话（Dialog）
- 多引擎本地对话（vLLM / llama.cpp GGUF / Transformers，按显存自动路由）
- 流式输出（WebSocket 实时帧推送），打字机效果
- 深度思考双通道（推理过程与正文分离呈现）
- 上下文记忆 + 知识库 RAG（可调温度 / 上下文长度，随模型能力自动适配附件入口）
- 图片（多图对比理解）与文档（txt/md/docx/pdf）上传，插件技能即焚注入
- 排队不秒拒、自动降级明示（装不下的模型自动换档并提示）
- 会话管理：重命名/置顶/搜索/批量删除/消息评分反馈

### ✍️ 写作台（Novel）
- **篇幅规划三参数**：计划章数 / 每章目标字数 / 卷数——大纲出纲与正文生成真实吃参数（附快捷档一键填）
- **降AI味文风三档**：标准 / 拟真·轻 / 拟真·重（低频词、禁模板比喻、情感层次、句长错落、人物语气区分），同章可对照
- **AI 大纲树**：灵感 → 卷/章细纲，逐节点可改可删，重新生成带覆盖确认
- **生成未完成章节**：批量补缺不覆盖已完成，队列可视可取消
- **角色 / 伏笔 / 世界观**：AI 设计角色吃补充要求、伏笔烂尾预警、世界观导入知识库联动正文
- **整本导出** TXT / MD，批量删除作品

### 🧠 知识学习（Learn）
- 文档 / 图片自动向量化入库（多道入库质检闸）
- RAG 检索增强生成（向量 + FTS5 全文 + RRF 融合）
- 知识图谱可视化，知识库批量删除 + 图片知识管理
- 浏览器代理自主上网学习（AI 控制 ↔ 用户接管即时切换）
- **学习分析报表**：效率/来源/趋势/主题对比，实时轮询刷新
- **学习配额可设置**：知识库容量上限自定义，接近上限预警
- 行为学习微调（操作偏好沉淀，手动触发）

### 🔊 语音能力（Voice）
- TTS 文字转语音（Windows SAPI5 本地语音）+ Whisper 本地语音识别
- 自定义音色上传（wav/mp3/flac/m4a ≤20MB），已内置于漫剧配音链路
- AI 声音克隆为规划中功能（本地开源栈调研阶段）

### 🧩 插件系统（Plugins）
- **CuteMamen 包格式**：自包含 tar.gz（manifest + 权重 + 三级记忆），支持纯数据档与含源码档
- **分级安全模型**：出厂件（进程内·已审查）/ 用户纯数据（进程内）/ 用户含源码（**子进程沙箱**——超时硬杀、内存上限、崩溃不连坐后端）
- **导入链**：AST 静态安检 + 大白话确认门 + 试装载 + 失败清场
- **信任徽章**：三档可视化（蓝盾出厂/绿库纯数据/橙盾含源码）
- **产品接线**：对话/小说/漫画三端技能插座（chat/novel/comic skill；出厂技能面为空——宁缺毋滥）、Rust 编译错误分类（演示件）

### 🖥 系统与运维
- **新手引导 + 快捷键**：十个功能页统一引导（首访自动弹 / 悬浮?随时重看）；Ctrl+K 全局搜索（七类目标一处搜）、Alt+数字切模块、Alt+N 新建对话
- **全局任务中心**：跨模块任务统一排队 / 取消 / 进度（顶栏铃铛直达），通知历史留痕可回看
- **生成物文件库**：图片 / 关键帧 / 视频 / 导出件一处浏览下载，灯箱预览
- **存储清理中心**：磁盘占用盘点 / 白名单一键清理 / 备份文件管理
- **硬件健康中心**：显存 / 内存 / 温度 / 磁盘四仪表三色预警 + 硬件自检（驱动版本 / 外部模型可达性）
- **操作审计日志**：删除 / 导出 / 设置变更 / 云端连接 / 激活解绑全留痕可查
- **数据安全底座**：备份加密（AES-GCM）+ 每日自动备份 + 断电自恢复（挂死任务清扫）+ 密钥保险箱（云端 Key 加密存放、日志与诊断包脱敏）
- **睡眠保护**：生成 / 训练持锁期间自动阻止系统睡眠，结束即恢复
- **删除分级确认**：轻 / 中 / 重三级模板（删什么 / 留什么 / 可否反悔三要素），全应用统一

## 📁 项目结构

```
OmniSpace/
├── src/               # 后端 + 内核统一扁平包（原 src/ + DistributedFormer 内核）
│   ├── api/               # 路由层（dialog / comic / manga / novel / learn / models …）
│   ├── services/          # 业务层 + 推理引擎 + 模型管理（含 Transformers 后端）
│   ├── engines/           # 资源层（GPU / VRAM / 内存管理）
│   ├── data/              # 存储层（DB / 向量 / 全文 / 图谱 / 加密）+ Rust 训练语料
│   ├── middleware/        # 横切层（错误处理 / 限流 / 互斥锁 / CORS）
│   ├── core/              # 内核层：DistributedFormer 脉冲主模型（CubeGPT）
│   ├── cutemamen/         # 内核层：CuteMamen 插件内核（路由/生命周期/三级记忆/包格式）
│   ├── codec/             # 内核层：脉冲 / 多模态编解码
│   └── training/          # 内核层：主模型 → 插件 知识迁移读出层
├── plugin/            # CuteMamen 插件包（.CuteMamen，自包含：manifest+权重+记忆）
├── frontend/              # React SPA
├── launcher/              # 启动守护进程（自检/端口/心跳/重启/启动页）
├── docs/                  # 完整文档（含 AGENTS.md / CLAUDE.md）
├── tools/                 # 构建与诊断脚本（第三方工具树不入库）
└── tests/                 # tests/unit 单元测试 + E2E 流程编排
```

## 🚀 快速开始

### 前置要求

- Windows 10/11
- NVIDIA GPU（≥ 16GB 显存 = 完整体验档；12GB = 降级体验档，自动走降级链）
- CUDA 12.x
- ≥ 50GB 磁盘空间（模型文件）

### 启动

```powershell
# 进入项目目录（公开仓库）
cd E:\OmniSpace

# 方式一：双击 启动OmniSpace.bat（免黑窗可用桌面快捷方式）

# 方式二：命令行启动（需先配置模型文件，详见部署手册）
runtime\py312\python.exe launcher\launcher.py
```

浏览器会自动打开 `http://127.0.0.1:8765`

> 端口说明：launcher 默认 `--port 8765`（冲突时先清理残留进程，再扫描 5800–5835 递进）；
> 开发模式直接跑 uvicorn 时用 `config.yaml` 里的 5800。

### 开发模式

```powershell
# 后端（端口 5800）
runtime\py312\python.exe -m uvicorn src.main:app --reload

# 前端（端口 5173，自动代理 API）
cd frontend
pnpm install
pnpm dev
```
