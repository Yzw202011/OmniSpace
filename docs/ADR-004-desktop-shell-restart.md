# ADR-004：桌面壳重启——推翻 ADR-002 的「launcher + 系统浏览器」交付形态

- 状态：已接受（Accepted，重启 ADR-002）
- 日期：2026-09-02
- 决策者：用户裁定（封装方向 = 桌面应用，交付对象 = 外部普通用户）
- 关联：ADR-002 §5 重启条件、`docs/封装发行计划.md`（唯一现行版）

## 1. 决策问题

ADR-002（2026-08-20）裁剪 Tauri 壳，维持「launcher 守护进程 + 系统浏览器」交付形态。现产品方向已转为面向外部普通用户商业发售（买断制，2027-02-28 前，旧 v2 已拍板决策由封装发行计划 §1 承接）。**ADR-002 §5 预设的重启条件 #1「需分发给非技术用户」已被命中**，按该 ADR 自身的可逆门规则重开决策。

## 2. 决策

**重启桌面壳**：以应用自有窗口（WebView 载体）替代系统浏览器作为用户界面；壳层架构收敛为「**一个窗口 + 一条关闭语义**」，boot.py 既有的生命周期机器（splash 体检/健康轮询/心跳/崩溃重启≤5/单实例互斥/优雅退出）全量复用，经 `--no-browser` 分支出窗（boot.py:412/910 现成）。

技术选型按封装发行计划 §3 执行：**pywebview 先行 PoC（六门槛硬验收）→ 不过即转 Electron 保底**；Tauri 维持不推荐（ADR-002 #3 的 Rust 工具链裁定未解除）。交付形态并行裁定为「全家桶免下载器」（用户 2026-09-02 裁定，体积与介质评估见封装发行计划 §0）。

## 3. 理由（逐条回应 ADR-002 当年三条裁剪理由）

1. **「单机交付已闭环，无用户反馈要求桌面窗口」→ 前提已变**。交付对象从单机自用变为不懂技术的外部用户：地址栏、端口号、"标签页关了后端还在跑"对小白是认知负担与事故源；关闭语义（排空确认 → /api/quit → 进程树收尾）同时结构性解决收尾计划遗留决策 #5（页面关闭全链退出）。
2. **「壳层增量价值 ≈ 0」→ 对商业产品不成立**。窗口/图标/任务栏/托盘属产品体验必需；前端为 Hash Router SPA，ADR-002 §4 原文即预留「未来若重启壳决策可零改动套入 WebView」——本次兑现该预言，壳层边际成本极低。
3. **「#38 <500MB 安装包锚点失效」→ 结论反转**。全家桶模式下交付单元是 ~272G 目录/硬盘，安装包体积约束同样失效，而壳层体积（pywebview ~3M / Electron +250M，对 6.5G 程序体是零头）不再构成否决项。
4. **成本核算更新**：pywebview 无新工具链（pip 进 pydeps 即可）；Electron 复用仓库现有 runtime/node-v20；两者均不触碰「内嵌 Python 零系统依赖」铁律的构建侧（Rust 除外，故 Tauri 仍出局）。

## 4. 后果

- RTM A-01 由 ⚪ 豁免恢复为**进行中**（载体：封装发行计划 S0~S4 里程碑）；
- pywebview 路线引入用户机依赖 WebView2 Runtime（Win10/11 基本自带；缺失时交付盘内置 Evergreen 离线包 + 首启检测引导，D4）；Electron 路线自带 Chromium 无此依赖；
- 关闭语义成为壳的强制验收项（任务管理器零进程残留）；
- ADR-002 保留为历史决策记录不删除；本 ADR 不改变「launcher 守护进程」地位——boot.py 仍是唯一生命周期监督者，壳只是它的"脸"。

## 5. 验证

S0 PoC 六门槛（splash→主界面切换/窗口尺寸位置记忆/X 触发优雅退出/绘画页 GPU 渲染/中文输入法/Win10 老机）；S4 纯白机验收；出门闸门全集见 `docs/封装发行计划.md` §6。
