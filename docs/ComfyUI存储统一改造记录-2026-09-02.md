## 深化（2026-09-02 第二轮）：空壳占位治理 + 纯净度绊线

**根因定位**：`ComfyUI/folder_paths.py:113-118` 在**模块导入期**无条件对默认路径（引擎树 `input/`）makedirs——执行时机早于 `main.py:174` 应用 `--input-directory`，故每次启动必现。**不会无限生成**：所有真实读写走重定向后的 `data/comfyui/input`，空壳只是 import 时刻的一次性 mkdir，永不收文件。

**两项落地**：
1. **自愈清除**（comfy_proc.py `shutdown()` → `_sweep_engine_placeholders()`）：进程终止后 os.rmdir 引擎树四个可写目录名（仅空目录可删，非空自动跳过）——引擎树静止态永远干净；若未来升级后空壳内出现文件，说明重定向被绕过。
2. **审计绊线**（dir_audit.py 新增 §5「引擎树纯净度」）：output/input/temp/user 四名下出现任何文件=违规（计入退出码）；空壳占位=◐ 提示不违规。运行期实测：拉起后空壳存在且 0 文件 → 关闭后自愈消失 → 审计「✓ 无可写数据落盘，1 个占位非违规」。

**运行期写入诚实盘点**（引擎树内除 models 外）：近 24h 零非缓存写入；`__pycache__` 39.1MB/224 目录为 Python 字节码缓存（代码树一部分，随代码变更有限更新，非产物/非用户数据，保留以保证启动速度）。

**验证**（00:5x）：编译过；spawn→空壳现（0 文件）→shutdown→空壳消失；dir_audit §5 全绿结论干净。
