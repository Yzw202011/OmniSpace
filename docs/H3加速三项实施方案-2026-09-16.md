## P-2 H3 SageAttention 增益实测（先行，半天）

- **改动清单**：无代码。`backend/config.yaml` 翻 `comfyui.use_sage_attention` 各一次 + 对照脚本（复用漫剧单镜 H3 任务，同种子同提示词）。
- **影响面**：零（测完复原）。
- **验证方法**：on/off 各跑 2~3 镜取中位墙钟；差 ≥10% 判有效；结果写回本文件附录。
- **风险回退**：config 复原即回。
- 意义：为 P-3 的耗时翻倍抵预算；图像侧已实测 +18%，H3 官方口径 ~2×（未本地验证）。

## P-4 T8 双时钟采样器（次行，~1 天）

- **改动清单**：`tools/ComfyUI_windows_portable/ComfyUI/custom_nodes/` 装 T8mars/comfyui-minimax-h3-audio-T8 节点包；`backend/services/inference/h3_chain_workflow_api.json` 采样段换 T8 采样器节点（门控开关 `config.yaml manga.h3_dual_clock: false` 默认关）；`h3_chain_engine.py` 读开关选节点。
- **影响面**：H3 采样段；音频链回归（T8 即 H3-audio 生态）；验收不过整体回退（工作流换回原节点+停用包）。
- **验证方法**：同镜同种子 on/off 对照（墙钟+多角色一致性目验+音频完整回归+队列取消回归）；≥30% 提速且质量不降才翻 true。
- **风险回退**：节点包停用不删（隔离观察）；工作流 JSON 在 git 内整体还原；社区「+100%/无损」口径未经独立复验——按实测数说话。

## P-3 H3 二采 1080p（末行，1~2 天）

- **改动清单**：`h3_chain_workflow_api.json` 新增二采节点组（低清初采→latent 放大→二次采样精修）；`h3_chain_engine.py` 质量档位表 `_QUALITY` 增 1080p 档（`{"480p","720p","1080p"}`）+ 档位→工作流参数映射；前端模型配置画幅选项增 1080p（`frontend/src` 画幅常量+下拉）。
- **影响面**：漫剧视频生成链唯一；**不挂默认**（新档开关式，默认仍 720p）——产能不受影响，按镜选用；音频链/取消链/进度广播回归。
- **验证方法**：同镜 720p 直出 vs 二采 1080p 对照（清晰度目验+单镜耗时记录）；社区「接近 4K」按 1080p 实测目验定；验收线=清晰度可感提升且耗时不超 2.2×。
- **风险回退**：档位表不挂默认，开关关即回现状；工作流 JSON git 还原。
