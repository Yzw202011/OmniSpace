## 二、方案（分批施工图）

### Z1 · Z-Image-Turbo 接入 comfy 第三引擎槽（1 人日）
1. 三件权重登录 comfy_model_map.json + 中央 models/ 落位 + 硬链（复用现有挂接机制）
2. comfy_paint_engine._build_workflow 增 z_image 工作流族：
   UNETLoader(z_image_turbo_bf16) + CLIPLoader(qwen_3_4b, type=lumina2) +
   VAELoader(z_image_ae) + ModelSamplingAuraFlow(shift=3) +
   KSampler(8步/cfg1/res_multistep/simple) + ConditioningZeroOut 负向
   （**参数固化官方基线**——二开矩阵已证无增益）
3. 模型选型面：paint 模型槽新增 model_id="z-image-turbo"（模块选型白名单同机制），
   draw.py comfy 分支按 model_id 分流工作流族
4. 验收：绘画页点名 z-image-turbo，同人像/四视图提示词 ≤15s/张@720p，
   "夏沐沐"名字渲染正确；与 klein 槽互切正常（现有 ensure_loaded/卸载机制复用）

### Z2 · 四视图链重构 MVP：分张+原生参考图条件+代码贴字（1~1.5 人日）
1. **零升级路线（本轮深挖定案）**：Z-Image 原生 TextEncodeZImageOmni 节点自带
   参考图条件（image1~3 + clip_vision，本机 0.34 已含该节点）——参考图锚身份 +
   每视图单独提示词（正/侧/背/特写各一条）+ PIL 合成中文标注（零错字，
   复用 comic_gen._generate_four_views 分张思路 + comic_asset 的 portrait_views 结构）
2. **不依赖 ControlNet、不升级 ComfyUI**——见风险节：姿势锁是增强项非前置项
3. 验收：四视图语义 4/4、标注零错字、跨视图一致性目验、总耗时 ≤45s
   （4×~8s + 合成）、与现产线 klein 四视图 A/B 不劣化

### Z2+ · ControlNet 姿势锁（可选增强，0.5~1 人日，**需单独拍板**）
- **硬事实（二轮深挖）**：本机 ComfyUI 0.34 的 controlnet 代码不含 Z-Image
  ControlNet 支持（grep 实证），加载 Union-2.1 会报 "controlnet file is invalid"；
  官方 changelog 确认支持在更新版本（老版本用户同报错，ComfyUI issue #11041/#11103）
- → 前置=**ComfyUI 便携包隔离升级**（克隆→升级→H3+绘画双回归→再切换）；
  H3 视频链是红线（用户令 09-06），回归不过不切换
- 收益：姿势骨架锁死每视图构图，一致性再上一档；骨架可用预画站立骨架
  （正/侧/背固定姿势，PIL 一次性生成）或 0.34 自带 SAM3D Body 姿态估计
  （nodes_sam3d_body，需 models/detection 下放检测权重）

### Z3 · Z-Image-Edit 指令编辑（1 人日，权重就位后）
1. 权重下载接入（官方家族，双语编辑指令；**风险：发布/镜像状态待代理恢复核实**）
2. 漫剧资产页"指令编辑"入口：改表情/姿势/换装/补写文字标签（替代/增强代码贴字）
3. 验收：真实资产图指令编辑实弹（改表情+补中文标签两场景）；四视图标签 AI 补写零错字

### Z4 · LoRA 训练补风格与角色一致性（1~2 人日）
1. ostris/ai-toolkit 部署：**8-12GB 显存实证可行**（社区 8GB@1024px/60 图、
   12G 经验帖 2000 步 1-2h、16GB 卡开量化余量充足；6-10 张样本即可成 LoRA）
2. 首训"3D GC 游戏风"风格 LoRA（补 P3 精修差距）；次训 Z-Image 角色 LoRA
