## 2. 关键量化证据

- 逐格交叉矩阵（v3，行=我们，列=竞品）对角线全部为行最大值，说明四格内容-景别映射与竞品一一对应，无错位：
  ```
  cell1: 0.675 0.160 0.193 0.090
  cell2: 0.504 0.605 0.515 0.366
  cell3: 0.477 0.416 0.437 0.342
  cell4: 0.088 0.288 0.433 0.691
  ```
- 场景忠实度是我们的强项：0.853 vs 竞品 0.610。竞品把场景画得更"自由"，我们经多参考条件注入把大门/三角梅/别墅/树影按资产图复刻。
- 竞品自身的身份锚只有 0.230：因为它按描述词渲染了马尾+白衬衫，偏离了人物资产图（披肩发+T恤）。**"全维度对齐竞品"与"对齐角色资产"在这一格上不可兼得**，见 §3。

## 3. 学说分歧（必须由产品裁决，不是技术缺陷）

竞品的实际行为是**描述词文本 > 资产图**（马尾/白衬衫/白行李箱都来自 C 段原文）；本项目经 v12（白色行李箱 vs 黑色资产）/v22（马尾 vs 披肩发资产）事故裁定的是**资产图为准**。本轮已实现 `text_priority` 开关（KeyframeGenerateRequest 新字段）：
- `false`（默认，项目学说）：v3——黑行李箱、黑发齐刘海，与资产完全一致；
- `true`（竞品学说）：v1——行李箱变白跟随文本；但发型仍被 PuLID 身份锁 + ReferenceLatent 参考链拉回披肩发——**要完全复刻竞品的"文本赢"，需要参考通道降权或文本锚增强，属后续迭代项**（诚实记录：当前开关只能部分翻转）。
- 手部泛红剥除（v64 渲染缺陷修复）不受开关影响，恒生效。

## 4. 本轮代码变更（全部经 130 项后端测试 + 实测验证）

### 4.1 节拍拆分（对齐竞品的关键修复）
`common.py` 新增 `_split_middle_shot_for_grid`：外贴竞品描述词常为 3 个内容镜头，网格协议需 4 格。此前走"等分时长+派生补齐镜"路径，格 3/格 4 内容与竞品错位；现在择非末镜中句数最多者按**倒数第二个句号**边界拆分（首版误用最后一个句号导致回退，离线验证抓出后修正），时间码按字数比例内插、保留描述词原始节奏。本输入实测：格2=低头看纸[3.5-5.2]、格3=抬头扫视[5.2-6.5]、格4=特写[6.5-10.0]，与竞品格序完全一致，且归一化幂等。

### 4.2 其余修复（审计问题，含波纹分析）
| 修复 | 波纹分析 |
|---|---|
| **P0-1** paint_engine img2img/inpaint 纳入 `_infer_lock`（Lock→RLock 防 inpaint→img2img 嵌套死锁） | 并发图生图串行化（本来就应串行）；generate 原有锁语义不变 |
| **P1-1** feature_lock 计数式重入 | 兼容训练服务私有字段直写降级路径（max(0,…) 钳制，终态不变）；现有调用方全部一次 acquire 一次 release，行为不变 |
| **P1-6** 资产 name/project_id 路径安全校验（models 校验器 + 上传端点） | 中文/空格放行，仅拒路径元字符与 `..`；存量中文名资产不受影响 |
| **P1-8** `(key)`→`(key,)` 流量配额 | **生产已自证**：修复后当日日志出现 `reason=traffic_limit`（修复前该值恒 0 永不触发） |
| **P1-9** learning_sessions 落库 dict→json.dumps | 会话记录开始真实落库；效率分析不再恒 0 |
| **P1-11** 启动时遗留 generating 视频任务改写 error | 与 flow_trace 孤儿恢复同时机；仅影响崩溃残留行 |
| `text_priority` 开关全链透传（端点→同步主函数→提示词构建器→一致性守卫重抽链） | 默认 False 行为与旧版完全一致；重抽链已同步透传，避免复评时学说漂移 |

### 4.3 遗留问题（诚实清单）
1. **画风未对齐**：`comic/art-style/list` 返回空——预置画风表无数据，V49 协议下项目风格行回退"网漫"，把画面锚向动漫厚涂；竞品是写实 CG。对齐路径：预置画风数据 + 项目选择 3D/写实画风（数据问题，非代码问题）。
2. text_priority 模式下发型仍被参考通道压制（§3）。
3. 格4"咬住下唇"类字面化幻觉属 seed 方差（v1 出现、v3 未复现），一致性守卫的重抽机制是现行兜底。
4. 审计报告中其余 P1/P2（锁体系统一、style 训练闭环等）未在本轮范围内，见 round-2026-08-28-code-audit.md。
