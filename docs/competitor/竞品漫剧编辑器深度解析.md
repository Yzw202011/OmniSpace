### 2.1 工序条（核心差异点！）

竞品工序条是**顶栏中央的渐变按钮组**（`.tb-btn--first/middle/last`），且**随作品类型切换两套工序**：

| 模式 | 工序 |
|---|---|
| 普通漫剧（5步） | 1 角色推理 → 2 角色生图 → 3 **分镜生词** → 4 分镜生图 → 5 生成视频 |
| 解说漫剧 COMM_MD（6步） | 1 角色推理 → 2 角色生图 → 3 **故事生词** → 4 **故事生图** → 5 **视频生词** → 6 生成视频 |

每一步点击 → 打开**统一的「积分消耗确认」弹窗**（mc-dialog，665px）：

- 标题：积分消耗确认（故事生图步骤特化为「故事生图确认」），配 jifenqueren.svg 图标
- 处理任务区：
  - 角色推理/生词类：「角色推理实际消耗积分按tokens计算」「分镜词和描述词实际消耗积分按tokens计算」
  - 生成类：「**N** 条视频/条人物、场景、道具/张分镜图 需要处理，共需消耗 **X** 积分」
- **全部生成 / 缺失生成** 下拉（isAll；某些状态隐藏缺失生成）
- 模型选择（按任务类型分三种表单）：
  - 推理类：推理模型（带 icon）+ 渠道 + 「xx%成功率 / 渠道不可用」
  - 图片类：图片模型 + 服务渠道 + 分辨率
  - 视频类：视频模型 + 服务渠道 + 时长/分辨率
- 提示：ⓘ 选择不同模型会影响处理速度与积分消耗。高成功率模型推荐用于重要任务
- Footer：取消 / **确认生成**
- 积分不足：拦截并弹「积分不足，请先充值」→ 唤起充值

**批量执行前置校验**（真实业务逻辑）：
- 角色推理：对勾选行调 `scriptReasoning{worksId, worksInfoIds[选中行], isAll}`，loading 文案「正在推理人物、场景、道具描述词」，自动切右侧到角色 Tab
- 分镜/故事生词：先校验已做角色推理（资源非空），再校验**每个资源都有名称**（「请检查右侧面板，存在"xx"没有名称，请先输入名称」）
- 角色生图：收集勾选行的 角色+场景+道具；isAll=全部，否则只取**缺图的**；逐资源进 loading 态
- 未勾选行：「请先勾选分镜行，再批量处理」
- 有任务在途：「当前有任务正在生成中，是否确认继续生成？」

### 2.2 顶栏其余入口

| 入口 | 内容 |
|---|---|
| 模型配置 | mc-config-dialog：推理/图片/视频三类模型的 类型+渠道+分辨率+画面比例+时长限制+fps:24(默认)，保存配置（`operateModel`），解说漫剧模式下隐藏 |

| 提示词 | prompt-dialog（530px）：提示词**套餐卡片**单选列表（label+desc，来自字典 ACTIVATION_CODE），切换保存（`typeChange`）——本质是激活码等级对应的提示词档位 |
| 设置▼ | settings-dropdown-menu：导入剧本 / 导出素材（二级菜单）/ 素材备份 / 退出编辑 等 |
| 积分 | 显示余额 + 「已激活」标记 |

### 2.4 中央分镜表（sb-*）

- 列：check / 序号 / 原文 / 分镜描述词 / 出场人物 / 场景 / 道具 / 分镜图 / 视频 / 操作
- **列宽可拖拽调整**（col-resizer），「拖动调整列宽，双击恢复默认」
- **行间插入**：每行之间有 row-insert-divider + divider-hitarea，点击在该位置「创建新分镜」

### 2.5 右侧资源面板（resource-panel）

- Tab：角色 / 场景 / 道具（rp-tab）
- 两个分区：
  - **作品中**（已绑定到当前选中行的资源）
  - **全部可用角色（N/M）**：可折叠标题 + 搜索框「搜索角色...」
- 资源卡片 res-card：缩略图（优先生成图）+ 名称（>6字 tooltip）+ hover 操作：
  - 已绑定显示「× 解绑」，未绑定 hover 显示「+ 绑定」（`bindResource`）
  - 生成中 ring-spinner 蒙层；批量模式显示 checkbox
- 「+ 添加」卡片 → 打开生成面板
- 点击卡片 → 进入**资源详情/生成面板**（见 2.6）

### 2.6 资源详情/生成面板（gen-*）

- 顶部大图预览 + 工具钮：复制 / 下载 / 送审
- 名称输入「请输入名称」（失焦自动保存 `operationResources`）
- 按钮行：**生成描述词**（AI 根据名称+上下文生成 notes）/ **本地图片**上传 / **AI改词**（见 2.8）
- 参考图上传：**最多 5 张**（SingleImageUpload，80×180 竖图）
- 描述词编辑区（rich-editor）
- **audioUrl 字段**：资源可挂音频（角色音色，「xxx(音色)」）
- AI生图按钮：校验激活码 → 名称非空 → 描述词非空（「请先生成AI描述词」）→ `aiGenerate(worksId, resourceId, count)` → 历史记录区逐版本
- 保存字段：{id, worksId, name, notes, type, imageUrl, referenceImage, **audioUrl**}

### 2.7 视频生成面板（选中行视频列时）

- 标题「{类型} 视频 详情」
- **数量计数器**（- N +，一次生成多条）+ **AI生视频** / **本地视频**上传
- **备选素材（N/6）**：上限 6 条；hover 工具条：选用(useFlag✓)/删除/播放/**画质增强**；失败任务显示 error-tooltip(notes)
- **历史记录（N）+ 查看全部**：可「从历史记录中添加」到备选
- 画质增强：读取视频元数据（宽高/时长/fps24）→ 携参跳转独立页 /quality-enhance
- 视频命名规则：`分镜{行}-{序号补零3位}.mp4`

### 2.8 AI 改词弹窗（ai-correction-dialog）

- 原文内容 textarea（6行，只读展示当前描述词/原文）

### 2.9 送审（内容审核，云平台特有）

## 5. 核心交互流程还原

1. **创建作品**：新建作品 → 手动(粘贴剧本)/自动(剧情文案or随机剧情+解说漫剧类型) → 选风格（或自定义风格） → 开始创作 →（自动模式 AI 推理分析拆分镜）
2. **角色推理**：勾选分镜行（或全选）→ 点工序「1 角色推理」→ 积分确认弹窗（tokens 计费说明+推理模型+全部/缺失）→ 确认生成 → 右侧自动切角色 Tab，AI 推理出人物/场景/道具及描述词
3. **角色生图**：资源补全名称 → 工序「2 角色生图」→ 弹窗选全部/缺失+图片模型+渠道+分辨率 → 逐资源出图（生成中蒙层）
4. **分镜生词**：工序 3 → AI 逐行写分镜描述词（可 AI 改词微调）
5. **分镜生图**：工序 4 → 逐行出分镜图（多版本历史，可送审）
6. **视频生词（解说漫剧）**：工序 5 → 生成视频描述词
7. **生成视频**：工序末步 → 视频模型+渠道+时长 → 逐行出片 → 备选素材选版本 → 画质增强
8. **资产绑定**：选中行 → 右侧资源卡 hover「+」绑定 /「×」解绑；原文里 @提及 引用资源
9. **导出**：设置 → 导出素材（分镜图/人物/场景/道具/备选视频/Excel 分镜表/整包素材备份 zip）

## 7. 最值得借鉴的 10 个设计点

1. **工序条即批处理触发器**：每个工序按钮 = 统一确认弹窗（任务量+费用+模型+范围），一次讲清楚"要花多少、用什么模型、处理哪些"
2. **全部/缺失生成**语义：重跑全量 or 只补缺口，避免重复扣费
3. **双模式工序**：普通 5 步 vs 解说 6 步（故事/视频 生词生图拆开），按作品类型切换
4. **资源面板「作品中 / 全部可用」双区** + 计数（N/M）+ 搜索，绑定关系一目了然
5. **备选素材池**（≤6）+ 历史记录回填：生成多个版本挑最好的，用 useFlag 标记
6. **AI 改词三段式**：原文 → 修改意见 → 结果预览 → 应用，比直接重新生成可控得多
7. **富文本描述词 + @资源提及**：描述词里直接引用角色/场景/道具实体，生成时自动拼装参考图
8. **行间插入分割线**：hover 行间隙出现 +，精确插分镜
9. **导出分层**：单类导出（图/视频）→ Excel 分镜表 → 整包素材备份 zip（带目录树），覆盖轻/重全场景
10. **队列弹窗与生成记录分离**：在途任务看队列（等待时间），历史任务看记录（7天留存+重新下发）
