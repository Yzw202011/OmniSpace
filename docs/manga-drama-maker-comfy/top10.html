D · 考古位其余（PanelComposer / sloppy-comic / StoryDiffusion / ai-comic-factory）PanelComposer = 网格协议排版侧原语（区域 conditioning 通道值得单独抄思路）；sloppy-comic = LLM→分格最简实现；StoryDiffusion = 一致性概念源头；ai-comic-factory = 部署范式教科书。均不投入主力时间。
