在 TRAE 中安装这些技能

所有入选技能均为 Anthropic Agent Skills 标准格式（目录 + SKILL.md YAML frontmatter），与 TRAE 技能体系同构——项目内 .trae/skills/html-report/ 就是这个布局。三种安装路径按推荐度排序：

方式一 · 复制到项目 .trae/skills/（推荐）

# 克隆仓库到临时目录，再把需要的技能目录复制进项目技能层
git clone --depth 1 https://github.com/obra/superpowers D:\tmp\superpowers
Copy-Item -Recurse D:\tmp\superpowers\skills\systematic-debugging e:\OmniSpace\.trae\skills\
git clone --depth 1 https://github.com/storyverse2025/storyverse-skills D:\tmp\sv
Copy-Item -Recurse D:\tmp\sv\skills\keyframe-prompt, D:\tmp\sv\skills\shots-prompt-writing e:\OmniSpace\.trae\skills\
为什么推荐TRAE 已验证能发现项目级 .trae/skills/<name>/SKILL.md（html-report 即此布局）。整仓库直接塞进去会引入大量无关 SKILL.md 干扰触发匹配，按需复制单个技能目录最干净，且技能随项目走、团队成员克隆即得。

方式二 · 通用 skills CLI

# 35+ agent 通用的安装器（Claude Code/Cursor/Codex/... 的技能目录约定）
npx skills add iliaal/ai-skills -s react-frontend
npx skills add mitch-avis/agent-skills -s sql-database
注意该 CLI 面向 Claude Code 等宿主的技能目录（~/.claude/skills/ 等），TRAE 不在其预设宿主列表。装完后仍需把目录复制/链接到 .trae/skills/。适合当"技能下载器"用。

方式三 · 装进项目自有 skills/ 目录做纯知识库

# 我们已有先例：skills/h3_convert 是给后端管线用的转换层技能
git clone --depth 1 https://github.com/MCKRUZ/ComfyUI-Expert e:\OmniSpace\skills\comfyui-expert
适用场景不追求 TRAE 自动触发，只想要一份可被 AI 按需读取的领域知识包（如 ComfyUI-Expert 的 15 个技能文档）时，放项目 skills/ 目录、在对话中点名引用即可，零宿主绑定。
安全红线（先读再装）技能包内可含可执行脚本（Python/Shell），加载即代表你信任作者。装前必做三件事：① 通读 SKILL.md 正文；② 检查 scripts/ 目录有无外发请求（curl/上传/token）；③ 只从本报告列出的仓库安装——这些仓库均经过社区大规模使用或来自可信组织（Anthropic / Trail of Bits / obra）。

漫剧短剧创作域 · 12 个技能 · 剧本→分镜→提示词→资产→审核

本版核心新增。7 个垂直仓库逐一核验：storyverse2025/storyverse-skills（专为竖屏 9:16 微短剧管线设计，直击提示词漂移）、Algovate/StoryForge（分镜师/导演/动画师三技能包，目标媒介就是短剧）、GongLingRui/screen-creative-skills（31 件影视创作全家桶）、Coconah/AI-Short-Drama-Agent-Skill（5 步法编剧）、mmlong818/claude-skills（女频微短剧）、0xsline/short-drama（全流程含合规出海）、chardigio/photo-novella-skill（照片小说/漫画书）。按我们 A/B/C 描述词协议的生产链路排序。

keyframe-prompt
P0
把 Spatial Bible（空间圣经）落成可复用的 Keyframe/scene-ref 基准帧提示词：锁定家具、光源、角色站位与机位坐标系；附填空模板、完整案例与 Beat 内精简 SPATIAL ANCHOR 写法。
命中痛点 scene 资产首图正是 scene_sim 门禁的基准（DINOv2 ≥0.60）；「已有 Keyframe 漂移 → 重出 scene-ref」与我们「场景漂移 → 换 seed 重抽」同题同解。C 段首帧保持段引入 SPATIAL ANCHOR 写法可直接防跨镜漂移（H3 latentRelay 的提示词侧互补）。
storyverse2025/storyverse-skills · 竖屏微短剧管线
shots-prompt-writing
P0
单 Beat → 15 秒内视频生成提示词：八区块结构、角色外貌锚定、机位推导（正反打/视线轴线）、走位调度、情绪物理化、V.O./O.S. 音频处理、NEGATIVE 锁定，外加生成结果排障手册。
命中痛点 H3 单段 5-15s 硬约束 × C 段 2-4s/镜贪心合并正是「Beat→shots」问题域；外貌锚定 = 我们的 <Subject N> 全项目稳定编号，NEGATIVE 锁 = A 段负向 token，排障手册（背对/视线错/背景错）可直接对照 h3_convert 转换层排障。

film-storyboard-skill
P0
分镜师技能包：剧本 → 节拍拆解（识别叙事拐点）→ 九宫格 Beat Board 静态分镜提示词 → 四宫格 Sequence Board 序列提示词；支持多集批量与断点续传。
