## 0. 共用验证基建（一次搭好，全批复用）

- **A/B 口径**：同分镜行+同 seed（`md5(row_id|seconds)` 天然同源）+ 同档位（质量档）
  + 单变量替换；产物落 `data/videos/h3_ab/p<批号>_<臂名>.mp4`
- **指标四件套**（judge.py 复用扩展）：拉普拉斯锐度 / 抖动 / 抽帧三时刻对比图 /
  100% 放大图；批 3 加「进度条单调性」检查（progress 回写序列无倒退）
- **ASR 台词泄漏闸**：Whisper 转写产物音轨，命中台词字数>阈值=朗读泄漏（B 段实验主指标）
- **要素命中清单**：描述词关键要素（人物/场景/动作/道具）人工抽帧核对表
- **测试行**：复用 row_v7_01；批 1 需新建「远景双人行走」测试行（独立测试项目，
  不碰真实项目——真实项目只读红线）
- **token 守卫**：六段式合同字符数上限告警（防模板注入撑爆 prompt，阈值按现行合同
  均值 ×1.5 暂定，实测后校准）

## 批 1：远景持续行走模板 + 空洞形容词 lint（最低成本，先跑通全流程）

**改动清单**
1. `h3_chain_engine.py` `_six_section` 链上新增 `_inject_distant_walk(shots_p, refs)`：
   C 段镜头检测远景/远处 + 人物主语 → 注入规范 §15.1 模板句（英译：
   "continue walking steadily throughout the entire shot... steps remain continuous"）
2. 新增 `_lint_generic_adjectives(text)`：检出 cinematic/dynamic/epic/high-quality/
   高质量/大气/有质感 等空洞词 + 上下文（仅运镜/动作语境）→ 输出替换建议表并
   记 debug 日志；**先只告警不替换**（观察一批发现行后批 2 再开替换）
3. 单测 `tests/unit/test_translocation_p1.py`

**影响面**：仅 H3 链式 prompt 构造；不改合同结构/不改进度映射；lint 告警不阻断生成。

**验证方法**
- 单测：远景句注入命中/不误伤近景；lint 对空洞词样例命中、对正常描述零误报
- 实弹 A/B：远景测试行 ×(模板开/关) 两臂，比对远景人物全程位移连续性（抽帧核对表）
- 回归：row_v7_01 一条（确认注入对普通场景零扰动 + token 守卫不超限）

**风险与回退**：模板注入撑长 prompt（token 守卫拦截）；误注入近景（正则限定
远景/远处/地平线 等词+距离词共现）；回退=删两个函数+单测，一处 revert。

**验收标准**：远景臂的人物在三个抽帧时刻均有连续位移而对照臂出现静止/消失；
lint 零误报样例通过；回归臂与现行产物差异仅限注入句。

## 批 2：动作链展开 + VFX 四要素（模板族主力）

**改动清单**
1. `_expand_action_chains(shots_p)`：动作动词词典（约 30 个高频动作：攻击/转身/
   爆炸/推门/拔刀/奔跑…）→ 规范 §8 八段式链（预备→触发→加速→主动作→接触→
   反应→恢复→终态）的静态英译模板；**仅当镜头含该动词且无既有过程描述时注入**
2. `_expand_vfx(shots_p)`：VFX 触发词（爆炸/火光/魔法/闪电/碎裂/烟雾…）→
   §10 四要素模板（触发点+形态+方向+环境后果）
3. lint 升级：批 1 观察期结束后开「替换模式」（空洞词→具体视觉指令，替换表落档）
4. 单测 `test_translocation_p2.py`

**影响面**：同批 1；prompt 变长幅度最大的一批（token 守卫是硬闸）。

**验证方法**
- 单测：动词词典命中/已含过程描述不重复注入/VFX 词共现
- 实弹 A/B：动作密集测试行（战斗/爆炸类，从真实分镜库只读挑选或新造）×(注入开/关)
- 指标：动作可读性人工评分（三时刻抽帧：动作阶段可辨）+ 要素命中清单 + 锐度/抖动

**风险与回退**：模板句与用户描述语义冲突（注入前做主语一致性检查）；过度模板化
导致镜头同质化（A/B 盲评把关）；回退=词典开关化（config manga.h3_action_chains，
默认关→A/B 胜出后翻默认）。

**验收标准**：动作臂在抽帧中呈现可辨的动作阶段（预备-接触-收势），对照臂孤立的
动词标签出现「瞬移/跳变」；token 不超守卫；盲评不劣于对照。

## 批 3：运镜五要素（动「固定机位铁律」，风险最高单独走）

**改动清单**
1. `_expand_camera(shots_p)`：检测运镜词（推进/拉远/环绕/跟随/俯冲…）→ 补全五要素
   （机位/景别+运动+方向+速度幅度+跟随对象，规范 §9 词典）；无运镜词的镜头维持
   「static locked-off shot」现铁律不变——**从一刀切固定升级为「具体或固定」**
2. 单测 `test_translocation_p3.py`

**影响面**：运镜文本进 prompt；进度映射不受影响（映射基于时间，与文本无关），
但需实证确认（历史 10-02 进度重置教训）。

**验证方法**
- 单测：运镜词补全/无运镜词维持固定机位
- 实弹 A/B：运镜描述测试行 ×(五要素补全/现行固定机位)；**进度回写序列单调性检查**
  为硬闸（progress 无倒退）+ 运镜表现抽帧核对 + 抖动指标（运镜臂允许 motion 升高，
  jitter 不应异常）

**风险与回退**：运镜导致画面不稳/晕动（盲评把关，劣即回）；进度异常（理论无关，
实证兜底）；回退=config 开关 manga.h3_camera_expand 默认关。

**验收标准**：进度单调 ✓；运镜臂运镜可辨且不晕（盲评）；固定机位镜头行为与现行
完全一致（回归）。

## 批 4：后拍时间戳（多镜精度）

**改动清单**：`_parse_c_shots`/`_six_section` 多镜路径——第 2+ 镜注入
`At 00:MM:SS.mmm` 时间戳（镜起点=前镜帧数累计/24fps，与 align_h3_frames 网格一致）；
单镜路径零变化。单测 `test_translocation_p4.py`。

**影响面**：仅多镜连播/多行 chain；单镜零扰动。

**验证方法**：单测时间轴计算（17k+5 网格对齐）；实弹=两行 chain 任务 ×(开/关)，
核对第二镜起始内容是否更贴描述词时间意图。

**风险与回退**：时间戳格式模型不识别（观察产物，无效即回退开关
manga.h3_shot_timestamps 默认关）；累计误差（用帧数真源计算不用秒估算）。

**验收标准**：多镜臂第二镜开场与描述词时间意图吻合度优于对照；单镜回归零变化。

## 批 5：OpenH3-IR 校验规则集对标（纯调研+移植）

**改动清单**：克隆 ruashots/open-h3-ir，提取其六段校验规则全集 → 对照咱转义层

**影响面**：只加校验（告警级），不改生成逻辑。

**验证方法**：对 row_v7_01 与测试行现产 prompt 跑新规则——报出的应为真问题；
误报率实测后调阈值。

**风险与回退**：规则语义不合咱 ABC 输入格式（逐条评估后才移植，宁缺毋滥）；
回退=删规则项。

**验收标准**：对标表落档 docs/；移植规则在存量 prompt 上误报率 <10%。

## 批 6：1k 语料对照实验（B 段理解度挂账的正主）

**改动清单**：下载 ostris/minimax_h3_1k 子集（或策展版 10 条+抽样 50 条）→
建《B 段要素→画面命中》对照实验：同一批测试行 ×(h3_keep_b_section on/off) 双臂
（config 开关现成）→ ASR 朗读泄漏账 + 画面要素命中账 → 回答「B 段该吞还是该蒸馏」。

**影响面**：零代码（开关现成）；产出一份数据报告。

**验证方法**：双臂各 ≥3 条不同题材；ASR 闸量化朗读差；命中清单量化画面差；
结论三选一：吞除维持（现状）/ 条件保留（特定题材）/ 蒸馏立项（接批 7）。

**风险与回退**：样本量小结论弱（如实标注置信度）；回退=无（实验性质）。

**验收标准**：实验报告落档 docs/，三选一结论+证据链，挂账销账。

## 批 7：lightx2v Prompt-Rewriter-LoRA A/B（模型路线 vs 编码路线）

**改动清单**：下载 pytraveler GGUF Q8_0（0.69GB）→ 离线批量：同批测试行描述词
经 Rewriter 生成六段式 → 与转义层输出并列 → 双路各实弹出片 → 对比裁决。

**影响面**：零生产码（离线实验）；结果决定是否给转义层加「模型预处理器」旁路。

**验证方法**：①意图保真：Rewriter 输出是否丢失/篡改描述词要素（清单核对）
②画质 A/B：双路产物四件套指标+盲评 ③成本：Rewriter 延迟/显存记账。

**风险与回退**：模型改写吞要素（咱转义层的核心优势就是保真，预期赢面大但用数据
说话）；VRAM 与对话引擎冲突（离线跑不在线）；回退=纯实验无回退需求。

**验收标准**：裁决报告落档（编码路线 vs 模型路线 vs 混合路线建议），挂账「蒸馏
方向」销账或转正。
