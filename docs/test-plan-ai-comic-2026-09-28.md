**已知历史坑（用例直接来源，全部本轮亲历）**：模型假切换史（方案2 已修）、模块白名单数据面滞后（新模型必补两槽）、让渡缺失致准入闸拒单（draw 链已补）、气泡把手可发现性、量词块副作用（z-base 特写偏斜已修）、klein 人脸干预已全线下线、AI 写分格/资产四视图链路从未在本轮实弹。

## 一、缺陷分级

- **P0**：崩溃/蓝屏/数据丢失/后端静默死亡/ComfyUI 僵尸进程
- **P1**：主功能不可用（生成失败无出路、产物缺失、项目/分格/资产删除不生效、导出包损坏）
- **P2**：功能缺陷（模型切换不真、气泡丢失/错位、进度失真、跨格串图）
- **P3**：体验/文案/样式（把手不显形、角标文案）

## 二、前置与环境

1. 后端 + 前端 dist 构建最新（五模型 COMFY_PAINT_MODELS 全 ready；`/draw/models` 恰好 5 项，默认 qwen-image-2.1）
2. 测试前跑一遍活动门：`/draw/queue` 空 + `nvidia-smi` 无 >1GB comfy 进程；**GPU 测试前必核后端实时任务**（并发立即停手）
3. 测试数据隔离：专建测试项目（命名带 `TEST-` 前缀），测完删；不碰「逆天邪神」等用户项目
4. 每轮证据落 `docs/测试记录/AI漫画-YYYY-MM-DD-RN/`（截图 + curl 响应 + 日志行）

## 三、轮次与用例

### R1 冒烟轮（15 分钟，先证活着）

| 6 | 预览 + 关闭 | 预览大图可开可关 |

### R2 模型切换诚实性轮（核心，本轮新修的主战场）
方法：每模型同提示词同 seed 出一张，**以日志 `model=` 与 `result.model` 为铁证**，不目测。
| # | 操作 | 过关标准 |
| --- | --- | --- |
| 1 | 依次显式选 5 模型各生成一图 | 每发日志 `model=<所选>` 且 `result.model` 一致；出图风格肉眼可辨差异 |
| 2 | 智能路由（清空选择） | 走默认 qwen21；无假切换（历史病根回归） |
| 3 | 选 klein-9b + 人物提示词 | 无人脸词块/精修干预（已下线——产物应原生质感，非白瓷脸） |
| 4 | 选 z-base + 人物提示词 | 偶像词块生效（脸精致）且**全身构图不偏斜**（特写偏斜已修回归） |
| 5 | 选 z-base 换非人物场景词 | 词块不注入（场景零变化） |
| 6 | 显存让渡：先跑一单（驻留模型占显存）再选 qwen21 | 让渡日志「生成前让渡」出现，不撞 COMFY_VRAM_INSUFFICIENT |
| 7 | 负面词：klein/z-base 零填写生成 | 引擎 neg 节点含「欧美人脸…」默认块；z-turbo 仍 ZeroOut |
| 8 | 模型设置保存后刷新页面 | 选择持久（module-config 槽）；弹窗内选型与设置页同源 |

### R3 分格与气泡编辑轮（纯前端 + 落库）
| # | 操作 | 过关标准 |
| --- | --- | --- |
| 1 | 添加分格 → 填描述词 → 生成 | v1 递增、版本角标正确 |
| 2 | 重新生成 | v2 出图且 v1 保留（版本链） |
| 3 | 台词气泡：写台词、选 5 种形状 | 形状渲染正确（对话/旁白/思考/喊叫/低语），保存后重进不丢 |
| 4 | 气泡拖动 | 位置跟随、松手落库、重进页面位置保持 |
| 5 | 气泡拉伸（右下把手） | 悬停显形（opacity≥0.55）、拖动变宽、高度随折行；宽度持久化 |
| 6 | 引用资产（若有角色） | 引用标签显示角色名，取消引用可逆 |
| 7 | 删除分格（含已生成画面） | 确认框 → 删除生效；**取消不动数据**（本轮教训回归） |
| 8 | 批量生成（未完成 N） | 逐格串行、进度逐格跳变、无跨格串图 |
