## 一、总纲

### 1.1 测试目的
1. 验证 11 个导航模块 + 启动链/激活门/云端链 的**端到端功能正确性**；
2. 用仿真人点击暴露「真人才会踩到」的交互缺陷（焦点/失焦/竞态/静默失败/文案误导）；
3. 用后端与链路监控验证「前端看到的」与「后端发生的」一致（无假成功/假失败/静默吞错）;
4. 量化性能与资源指标，锁定稳定性边界（RAM/显存/温度/长跑）；
5. 主动攻击边界与漏洞面（注入/穿越/并发写/取消语义/绕激活）。

### 1.2 严格度分级
| 级别 | 含义 | 执行要求 |
|---|---|---|
| **P0 阻断级** | 坏了软件不可用/资损/数据丢失 | 每轮必跑，任一失败=本轮判废 |
| **P1 严重级** | 核心功能受损或误导用户 | 每版必跑，失败须修复或挂账 |
| **P2 完整级** | 边角/体验/性能精调 | 发版前全量跑一遍 |

### 1.3 判定符号（沿用诚实取证铁律）
- ✅ 通过：步骤全走完且全部预期成立，有取证；
- 🔶 有条件通过：主路径成立但存在已登记的已知缺口（须注明对照编号）；
- ⚠️ 未测/证据不足：不得替用户宣称通过；
- ❌ 失败：任一预期不成立，须附取证与初判根因。

## 三、仿真人操作纪律（每条用例生效，违者判该用例无效）

1. **先 snapshot 后动手**：任何点击前必须有 DOM 快照证据；定位表达式须唯一（count==1）。
2. **复合可访问名用正则**：按钮名是拼串（如「加载 · qwen35-9b」），用唯一特征子串正则锚定。
3. **受控组件用 fill**：输入框 fill 后**必须失焦（blur/点别处）再断言**——onBlur 保存类控件不失焦=没保存。
4. **每次点击必须断言效果**：重渲染窗口期点击会静默无效，禁止「点了就算」。
5. **视觉结论必须截图/DOM 双证**：VLM 幻觉风险高，布局断言以 DOM 量测为准，截图仅作旁证。
6. **人类节律**：连续操作间隔 300~800ms 随机化，模拟真实手速（暴露防抖/竞态类缺陷）。
7. **不碰真实用户数据**：只用 `TESTAUTO-` 前缀测试项目与测试资产；微微一笑/倾城一笑/逆天邪神等真实项目**只读不动**。
8. **GPU 纪律（§16.6）**：任何 GPU 用例开跑前必查后端实时任务；发现并发任务立即停手，**绝不重启/杀 5800 后端**。
9. **烧钱用例（标 💰）**：云端真实计费（出图/视频/长文），每单开跑前须用户拍板。
10. **失败不停手原则**：单条失败继续后续用例（除非触发熔断），失败原因记录在案。

### 熔断纪律（立即停整轮）
- RAM 提交余量 < 2GB（历史 WER RADAR_PRE_LEAK_64 静默死亡线）；
- GPU 温度 ≥ 90°C 且持续 2 分钟；
- 后端静默死亡（/health 连续 3 次超时）→ 取证后走**正规退出链**（5850 POST，5800 /api/quit 是假货回 200 不退出）；
- 发现并发会话在飞任务 → 停手记录，等窗口。

## 六、用例正文

> 格式：每条含 前置 / 步骤（仿真人）/ 观测（后端链路）/ 预期与指标 / 取证。
> 💰 = 真实计费须逐单拍板；🔒 = 只读保护（禁改真实数据）。

### A. 启动链与激活门（10 条）

**A-01 冷启动到可交互全链计时（P0）**
- 前置：全进程冷态（无 python/pythonw/comfy 残留，任务管理器核验）。
- 步骤：仿真人双击启动器 → 盯启动页 HUD 逐阶段 → 进主界面 → 依次点开 11 个导航路由。
- 观测：/health 轮询、backend.log、HUD 阶段文案。
- 预期：HUD 阶段单调推进不回退；冷启动 ≤120s（M1）；11 路由零白屏零崩溃。
- 取证：HUD 截图序列 + /health 时间戳序列 + 各路由 DOM 快照。

**A-02 单实例守卫（P0）**
- 前置：已有一个实例在跑。
- 步骤：仿真人再次双击启动器。
- 观测：第二个实例行为、5800 端口、日志。
- 预期：第二实例被守卫拦截（提示已有实例），**绝不出现双后端**；原实例不受影响。
- 取证：双实例并存前后的 /health 与进程清单。

**A-03 跨副本接管闸（P0）**
- 前置：另一 copy_id 的实例占着 5800。
- 步骤：本副本启动，观察是否抢端口。
- 预期：拒接管、明确提示；**绝不重启别人后端**。
- 取证：启动日志 + 原实例仍存活的 /health。

**A-04 正规退出链（P0）**
- 前置：正常运行态。
- 步骤：仿真人走启动页「退出」。
- 观测：进程树（含 comfy/vllm 子进程）逐一退出。
- 预期：全部子进程 30s 内退净；验证 5800 /api/quit 假回 200 坑不复发（退出走 5850）。
- 取证：退出前后进程清单 diff。

**A-05 激活门·未激活灰置全链（P0）**
- 前置：dev 用 OMNISPACE_FORCE_LICENSE_PAGE=1 预览钩子或桩服务注入未激活态。
- 步骤：仿真人尝试 ①直开 5800 绕过启动页 ②在灰置界面用 Tab/Enter 键盘穿透 ③用开发者工具改 DOM 删 license-locked 类 ④重启后端重试。
- 观测：后端业务 API 返回码、body.license-locked 类、LicenseGate 弹层。
- 预期：未激活时所有业务 API 403；灰置+遮罩不可穿透；刷新/重启不豁免。
- 取证：403 响应样本 + 键盘穿透尝试后的 DOM 断言 + 截图。

**A-06 激活门·正常激活流（P0）**
- 前置：测试码（发码台生成，六种时限码各一）。
- 步骤：输入码 → 勾选同意 → 激活 → 重启验证持久。
- 观测：license 落盘、fingerprint、后端闸放开。
- 预期：激活成功→灰置解除；重启后仍激活；指纹=本机 3 指纹 2/3 容错口径。
- 取证：激活前后 /health+许可信息对比。

**A-07 激活门·坏码与过期码（P1）**
- 步骤：仿真人依次输 ①乱码 ②过期时限码 ③被吊销码 ④他人机器码（指纹不符）。
- 预期：四类都拒绝且**错误文案可懂**（不泄露内部细节）；拒绝后可继续重输。
- 取证：四张拒绝提示截图 + 后端许可日志行。

**A-08 时钟回拨对抗（P1）**
- 前置：已激活的时限码。
- 步骤：系统时间前拨 1 天/回拨 30 天后再启动。
- 预期：时限码不因回拨无限续命（有回拨检测或宽限策略），行为与设计一致。
- 取证：改时间前后的许可校验日志。

**A-09 启动中断恢复（P1）**
- 步骤：在 HUD「模型装载/引擎启动」阶段强行断电级杀进程 → 再启动。
- 预期：二次启动自愈（断电自愈链）；无残留锁文件卡死；数据无损。
- 取证：两次启动日志 + 数据库完整性 PRAGMA。

**A-10 升级链烟测（P2）**
- 前置：测试升级包（Ed25519 签名）。
- 步骤：正常升级 / 坏签名包 / 断电中断升级三线。
- 预期：坏签名拒装；中断后回滚不砖（对照已知 R17 升级回滚缺口，🔴已知项可记🔶）。
- 取证：三线各自的版本号与启动结果。

### B. AI 对话（9 条）

**B-01 新会话冷装载全链（P0）**
- 前置：对话模型未装载（真使用时才装载铁律）。
- 步骤：仿真人新建会话→输入一句中文→发送。
- 观测：装载事件、vLLM/云端路由、WS 流帧。
- 预期：自动装载→续跑→流式回复；首字冷态 <120s（M3）；无「请先加载模型」类死胡同。
- 取证：WS 帧序列 + 装载日志 + 首字延迟数。

**B-02 流式输出完整性与停止（P0）**
- 步骤：长回复中途点「停止」。
- 预期：立即停；已出内容保留；会话状态一致；后端无悬挂任务。
- 取证：停止前后 WS 帧 + 后端任务快照。

**B-03 模型切换与降级气泡（P0）**
- 前置：9B 装不下场景（或注入降级态）。
- 步骤：选大模型发起对话。
- 预期：自动降级时气泡警示+degraded_from 字段如实；**不静默谎报**。
- 取证：气泡 DOM + 会话记录 JSON 的 degraded_from。

**B-04 对话设置四控件生效（P1）**
- 步骤：右栏调温度/上限等四控件→发消息→复位。
- 预期：参数透传到推理层（日志对账）；模型标签显真名。
- 取证：请求参数日志行。

**B-05 文件上传（txt）对话（P1）**
- 步骤：上传两个 txt→基于文件提问。
- 预期：两次上传都生效（filelist 快照坑不复发）；内容引用正确。
- 取证：上传后请求体含两文件摘要。

**B-06 历史会话持久化（P1）**
- 步骤：造 5 轮对话→退出项目→重进。
- 预期：全部轮次/角色/降级标记完整恢复。
- 取证：重进前后会话 JSON 对比。

**B-07 云端绑定对话（P1）**
- 前置：绑定 cloud:prov:gpt-5.2（或 gpt-6-astra）。
- 步骤：发起对话→断网重试。
- 预期：云端路由命中；断网错误带出路（不假成功）；ReadTimeout 不双发。
- 取证：云端调用事件行 + 错误气泡截图。

**B-08 敏感/超长输入边界（P2）**
- 步骤：粘贴 10 万字文本、纯 emoji、控制字符 \x00。
- 预期：有截断/拒绝且文案明确；后端不 500 不挂起。
- 取证：三类输入的响应与日志。

**B-09 对话中切换项目（P2）**
- 步骤：A 会话生成中切到项目 B 再切回。
- 预期：会话不串号；生成中任务状态如实。
- 取证：两项目会话列表 DOM 对比。

### C. AI 写作台（8 条）

**C-01 新建小说+首章生成全链（P0）**
- 步骤：仿真人新建 `TESTAUTO-小说`→填设定→生成第一章。
- 观测：novel.text 路由（本地/云端）、flow_trace。
- 预期：章节产出、字数在设定带内、落库可重进。
- 取证：章节文本 + flow_executions 行。

**C-02 续写与上下文连贯（P1）**
- 步骤：连生 3 章，每章后人工抽查主角名/前情引用。
- 预期：主角全勤（历史病=主角失踪）；无重复章（三层防重复闸生效）。
- 取证：3 章文本 + 质检闸输出。

**C-03 九道质检闸实弹（P1）**
- 步骤：故意构造病文（感叹号轰炸/虚词雪崩/剧本化）触发闸。
- 预期：闸门如实报告且「修文优于拒绝」；报告人话可懂。
- 取证：闸输出 JSON/截图。

**C-04 章节编辑与保存（P0）**
- 步骤：改一章文本→**失焦**→刷新页面→重进。
- 预期：编辑持久化（对照已知「小说编辑器零保存」缺口，🔴可记🔶）。
- 取证：编辑前后 DB 行对比。

**C-05 体裁/风格切换（P1）**
- 步骤：切两种体裁（如短篇/剧本）各生一段。
- 预期：体裁铁律生效（剧本化体裁不得散文腔）。
- 取证：两段输出对比样本。

**C-06 生成中取消（P1）**
- 步骤：章生成中点取消。
- 预期：停止扣费链路（云端）/停止推理（本地）；状态落 cancelled 不残留 running。
- 取证：任务行终态 + 云调用事件。

**C-07 删除章节/作品（P2）**
- 步骤：删 `TESTAUTO-` 测试章节→再删整个测试小说。
- 预期：确认弹窗到位；删除彻底（DB+文件）且不连坐他章。
- 取证：删除前后 DB 计数 + 目录清单。
