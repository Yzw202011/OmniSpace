# 漫剧创作模块 · 全维度测试计划 v1

> 制定:2026-08-30。依据:第 0~6 轮引擎验证、两轮颗粒级审计、三次排障的实测证据。
> 原则:**每轮只验一类事,过了才进下一轮;每个用例都有过关标准;先便宜后昂贵;不带病进下一轮。**

## 〇、被测对象地图(范围)

| 层 | 组件 | 入口/载体 |
| --- | --- | --- |
| 前端 | 漫剧工作台(项目卡片/分镜表/检查器/资产面板/五步流程/生成记录) | `#/storyboard`,dist 构建产物 |
| 后端 API | comic(项目)/comic_asset(资产)/comic_gen(资产生成)/storyboard(分镜行)/keyframe(关键帧)/video(视频任务+H3 链式派发)/voice/dialog | `/api/v1/manga/*` |

已知风险输入(用例直接来源):显存叠载史、后端静默死亡史、cssc 烧字资产、绑定名模糊匹配、LoadImage 子目录限制、17k+5 网格、720p≤8s 上限、台词烧字幕、删除瞬时 404(已加重试)、LTX 旧路与新引擎并存。

## 一、缺陷分级

- **P0**:崩溃/蓝屏/数据丢失/静默死亡复现
- **P1**:主功能不可用(生成失败且无明确报错、产物缺失、删除不生效)
- **P2**:功能缺陷(结果错误、进度失真、报错文案不可懂)
- **P3**:体验/文案/样式

## 二、轮次与用例

### R1 接口契约轮(后端 API 全量,约半天)
方法:curl/脚本逐端点,正例+反例+边界。
- **项目/分镜行**:create/list/update/delete 正反例;行删除后 keyframes/video_tasks 是否级联或保留(定义预期);sort_index 移动边界(首行上移)。
- **资产**:create/list/update;解绑(仅解绑不动文件)实测;删除资产后被绑定行的显示;跨项目同名资产隔离。
- **关键帧**:generate/batch/regenerate/rollback/list;version 递增与 is_current 切换;delete 后 current 回落。
- **视频(H3 链式)**:row_ids 单镜/多镜;seconds 3/15 越界拒绝;720p>8s 拒绝(60001);缺绑定资产拒绝(60001);row 不存在(40005);status 轮询字段;result 的 file_exists/download;cancel 生效。
- **过关标准**:全部端点按文档行为响应,错误码与契约 v1 一致,无 500。

### R2 数据层轮(约 2 小时)
- WAL 并发写:视频任务进度回写(每 3s)与分镜行保存并发 10 分钟,验证零 busy 报错(busy_timeout=10s 生效)。
- 迁移:user_version 升级路径 dry-run(备份 db 后模拟低版本)。
- 备份恢复:db 文件冷备→恢复→全功能冒烟。
- 磁盘占用:comics/keyframes/videos 目录增长审计,孤儿文件(无 DB 行的文件)清点。
- **过关标准**:零"database is locked";孤儿文件有清单与清理工具。

### R3 引擎轮(分引擎,约 1 天)
- **H3 链式**(引用已完成的第 0~6 轮结论作回归基线):单镜冒烟 10 项固定集(提交→done→文件→前端可见→显存回落)。
- **绘画 FLUX2+PuLID**:角色生图(正脸参考)→ 人脸一致性抽查;**PuLID 关/开对比**;烧字回归(生成图不得出现任何文字,含角色名)。
- **SDXL 回退路**:FLUX 卸载态下资产生成走 SDXL,产物规格与登记正确。
- **LTX 旧路**:`model_override="local"` 回落验证 + audio_path 音画同步路径验证(≤10s 限制)。
- **对话引擎**:分镜生词(需模型加载);加载失败的报错文案(应为"请先在对话模块加载模型"而非含糊报错)。
- **过关标准**:各引擎产物规格正确、登记完整、互不踩踏。

### R4 前端交互轮(代操作 + 戏剧化路径,约半天)
- 五个已修 UI 点回归:描述词折叠/点击展开/滚动条;进度框不撑布局;视频点击大窗预览;视频/分镜图/资产图右键下载(下载文件可播放/可打开)。
- 分镜行:删除(前端删→后端行消失→关联显示级联)、上下移、锁定、勾选批量条。
- 生成记录弹窗与任务状态同步(含失败态显示)。
- 断网恢复:后端重启后点"重试"恢复加载。
- **过关标准**:全部交互无布局错乱、无控制台报错、状态与后端一致。

### R5 集成链路轮(端到端一整集,约半天)
- 五步全流程:角色推理→角色生图→分镜生词→分镜生图→生成视频,以《123456789》项目 3 镜为例跑通。
- 校验:每步产物登记正确、分镜图/视频列计数同步、跨镜角色一致性抽帧、音频有轨。
- **过关标准**:3 镜全 done、无人工干预、总耗时在档位表预期内。

### R6 异常与恢复轮(故障注入,约半天)
- ComfyUI 进程杀掉后提交任务 → 报错文案明确(60003),引擎可自动重启 ComfyUI。
- 生成中杀 ComfyUI → 任务 failed,可续跑(start_clip)。
- 看门狗:手动杀后端 → 30s 内自动拉起。
- 双任务并发 → 功能锁拒绝语义正确(不静默丢任务)。
- 磁盘满模拟(临时小配额目录)→ 报错清晰不损坏数据。
- **过关标准**:每类故障有明确报错、恢复路径可用、无 P0。

### R7 性能与资源轮(约半天,挂机为主)
- 档位表复测填终值:480p@10s/15s、720p@8s(耗时/显存峰值/温度)。
- 连续 3 集 + 期间开关漫剧页(对话模型换载)——盯三红线:显存 15.8G/温度 83°C/静默死亡。
- RAM 峰值记录(≥90% 次数统计),为"加内存"决策留数据。
- **过关标准**:零静默死亡;红线零触碰;资源回落正常。

### R8 安全轮(约 1 小时)
- 回环绑定(仅 127.0.0.1);路径遍历(media 路由 `../` 注入拒绝);中文/特殊字符文件名;超长描述词(截断保护)。
- **过关标准**:全部门拒绝非法输入,无路径逃逸。

### R9 回归冒烟(长期机制,每次变更后 10 分钟)
固定 10 项:项目列表/分镜行折叠展开/单镜链式出片/视频预览/右键下载/关键帧版本/资产右键下载/失败报错文案/显存回落/看门狗存活。

## 三、测试数据与环境

- **数据源**:一律用项目真资产(竞品对齐-夏沐沐:夏沐沐/刀客立绘、望云亭苑/街角大门场景、行李箱/笔记本/三角梅道具)——教训:参考图错位是一致性问题的历史根因。
- **测试产生的临时数据**:先备份(json)后清理;已完成验证的测试行/关键帧随手删。
- **环境**:后端 5800(runtime/py310)+ ComfyUI 8189(便携版)+ 看门狗可选;每轮开跑前 `/free` 清显存。
