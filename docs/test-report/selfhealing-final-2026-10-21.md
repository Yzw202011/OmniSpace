## 七、方法论沉淀（六条）

1. 受控注入是验自愈的唯一路径（零天然故障=什么都验不出）。
2. 重启七步法：核查→埋幽灵→quit→pythonw 重拉→验收→清理→记录。
3. 前端自愈行为走 vitest 假时钟（客户端软断在产线构建不可行）。
4. IAB 实测三件套：dispatchEvent 兜底 / 整页 reload 解缓存 / 启动页就绪即跳转。
5. 定罪"缺日志/缺覆盖"前必须穷举源码全部措辞（三次翻案的共同教训）。
6. stash 对照定性存量红：失败先对照改动前基线，绝不混入本线结论。
