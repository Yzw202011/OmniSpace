## 四、测试方法论沉淀（可复用）

1. **重启窗口七步法**：战场核查（并发 commit/事件账/四表快照）→ 埋受控幽灵 → POST 5850 /api/quit → powershell pythonw 脱离会话重拉 → 验收 → 清理 → 记录。全程不碰 kill。
2. **受控注入是验自愈的唯一途径**：四表零天然幽灵时，不注入就什么都验不出来（SELFHEALTEST 前缀+验后即删）。
3. **IAB 前端实测**：role-click 必超时 → evaluate dispatchEvent 兜底；合成点击不咬 → 整页 reload；本产品就绪后 5850 自动跳 5800/#/chat。
4. ** 客户端软断不可行**（产线构建拿不到 socket 句柄）→ ws 自愈族改走 vitest 假时钟单测（429e1977），比浏览器抓拍更确定。
5. **stash 对照定性存量红**：每一笔失败先对照改动前基线，存量/并发域失败绝不混入本线结论。
