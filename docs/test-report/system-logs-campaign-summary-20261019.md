## 四、方法论沉淀（反假阳/反幻觉工具教训）

1. resource timing **250 条缓冲上限会骗出"零请求"假阴性**——验轮询看 startTime 序列；
2. 截图为降采样显示，**禁止按显示图读坐标**（两次点空事故）；
3. React 受控输入：`fill("")` 与 `cua.type` 穿不透，`fill(文本)+press("Enter")` 为已证组合；
4. IAB role-click 大页面持续超时→`dom_cua` 节点点击兜底；节点行消失类"异常"先直查 DB 再定性；
5. TestClient 离线验证带真实数据面副作用且全量 lifespan 过重，慎用；
6. **并发战役过夜不安静已三轮实证**——长任务验证封板比重跑诚实。
