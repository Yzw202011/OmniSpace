# OmniSpace · 本地 AI 创作工作站

> **把整个 AI 工作室，装进你自己的电脑。**

## 一句话介绍

OmniSpace 是一套装在你自己电脑上的全能 AI 创作软件：从一篇故事到一部会动的漫剧，从一句话到一幅画，从随口提问到专属知识库——六大能力全部在你本机的显卡上运行，**创作过程不需要联网，数据永远不出你的电脑**。

## 六大核心能力

**① 漫剧创作（招牌功能）**
把小说或剧本拖进去，AI 自动完成：切分镜 → 生成角色设定（含四视图）→ 关键帧 → 视频成片。上千张金标准画风卡（1117 张）+ 30 组风格包定调画面，分镜一致性技术让角色跨镜头不"变脸"。不会画画、不会剪辑，也能产出"能直接发出去"的 AI 漫剧短片。

**② AI 绘画**
多个旗舰级本地绘画大模型，中文描述直接出图；支持参考图控制风格，任务自动排队、进度实时可见，出图节奏由你的显卡说了算。

**③ AI 对话**
本地大语言模型，支持图片理解和"深度思考"开关。写文案、改剧本、当策划顾问——不用付 API 费用，也不怕对话记录上云。

**④ 知识学习**
把你的文档、设定集、资料喂进去，自动建成本地知识库与知识图谱；之后提问会引用你自己的资料来回答，适合长篇创作的世界观管理。

**⑤ 语音**
本地语音转文字（Whisper 转写），配合成片流程做配音，全流程不出本机。

**⑥ 视频风格**
专属画风 LoRA 的训练与管理，把"你独有的画风"变成可复用的资产，让每部短片都有辨识度。

## 客户为什么选它

- **隐私绝对安全**：全部 AI 推理在本地显卡完成，断网照常用。商业素材、未发布作品、私人资料零外泄。
- **一次买断，拒绝订阅**：付一次，永久用。激活码支持离线激活，无月费、无按张计费、无隐藏收费。
- **开箱即用的小白友好**：一键启动；模型没加载会自动加载并显示进度；显存不够自动切换轻量模型，功能不中断——不需要懂任何技术。
- **专业级出片效果**：风格包体系 + 分镜一致性技术 + 全流程一站式，从灵感到成片不出软件。
- **可持续成长**：模型可自主导入扩展，画风库持续更新，越用越顺手。

漫剧 / 动漫短片创作者、网文与剧本作者、自媒体人、插画与设计从业者、电商内容团队，以及所有"想用 AI、又不想把数据交给云端"的个人和小工作室。

## 硬件配置要求

OmniSpace 是本地推理软件，性能上限由你的电脑决定，**必须配备 NVIDIA 显卡**（显存大小直接决定体验档次）。

| 配置项 | 最低配置 | 推荐配置 | 生产力配置（官方实测基准） |
|---|---|---|---|
| 操作系统 | Windows 10 64 位 | Windows 11 64 位 | Windows 11 64 位 |
| 显卡 | NVIDIA 8GB 显存（RTX 3060 / 4060 级） | NVIDIA 12–16GB（RTX 4070 / 5070 级） | NVIDIA 16GB+（RTX 5070 Ti / 4080 及以上） |
| 内存 | 16GB | 32GB | 64GB |
| 硬盘 | 250GB 可用空间（SSD） | 500GB 可用空间（NVMe SSD） | 1TB NVMe SSD |
| CPU | 4 核以上 x64 处理器 | 6 核以上 | 8 核以上 |
| 网络 | 仅首次激活、下载模型、软件升级时需要；日常创作全程可离线 | 同左 | 同左 |

### 体验差异说明

- **8GB 显存**：AI 对话、AI 绘画流畅可用；视频生成使用轻量模型，速度较慢。
- **12–16GB 显存**：全功能流畅体验，漫剧视频正常速度出片。
- **16GB 以上**：可加载更大的对话/视频模型，批量出片更从容。
- 显存不足时软件会**自动降级到轻量模型并提示**，功能不会中断；若需运行 14B 级大型对话模型，建议 16GB 以上显存。
- 安装包已含常用基础模型，装好即可出第一张图；**完整模型库约 300GB**（含视频生成全量模型），通过夸克网盘按需下载或离线导入，不必一次装满。
- 官方实测基准机型：RTX 5070 Ti（16GB）+ 32GB 内存，全功能长时间稳定运行。
