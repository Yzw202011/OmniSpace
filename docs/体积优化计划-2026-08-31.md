# OmniSpace 体积优化计划（2026-08-31 摸底，v3 三轮颗粒级修订）

E 盘 582G，已用 450G，可用 132G。**项目本体 ≈ 448G，占全盘 96%**；代码与工程文件合计不足 10G，其余全是模型。

**硬约束：任何清理不得影响项目功能。** 执行规程见第四节（隔离区 + 冒烟 + 一键回滚）。

**三轮分析**：① 盘级账本 → ② 目录内部颗粒（每个模型目录逐文件） → ③ 跨目录同族聚合 + 字节级同源验证 + 工程目录清点。

## 四、零影响保障机制（执行规程）

1. **隔离区**：E 盘 `_trash_staging/`，清理项**同盘移动**（秒级、不占新空间、不动硬链接 inode），观察 7 天再真空删。
2. **A3 硬链接合并例外**：先备份 vace 侧三分片路径名清单 → `os.link` 挂接 → 冒烟通过后原文件已在隔离区；异常时从隔离区移回即恢复双独立副本。
3. **删前复核**：每项再跑全库引用 grep（含 ComfyUI user 工作流目录）+ models_manifest 登记同步检查。
4. **删后冒烟（当日全绿才算数）**：后端启动 + 前端打开；SDXL 绘画一张（验 A2）；qwen-image 绘画一张（对照）；AnimateLCM 视频一段（验 A1）；**vace 与 wan22 各跑一段**（验 A3 硬链）；漫剧 h3 链式全流程（对照）；ComfyUI 服务拉起；OmniLearn 知识库检索一次（验 A4/A5）。
5. **回滚与兜底**：任何异常从隔离区原路移回；即使误删，全部大文件有 ModelScope/HF 公开源可回补。
6. **防复发**：`tools/hardlink_sync.py` 巡检 nlink=1 的大文件自动建议挂接；output/temp_uat/_tmp_* 进 .gitignore + 定期清理；发行包只带代码+运行时（<10G），大模型走 modelxiazai 下载器（衔接封装发行方案 P0~P8，本计划保留清单=下载清单蓝本）。
