## §四 现实约束（每项升级前的硬核对，违一即砍）

3. **H3 主力锁定**（09-06 令）：视频域只动链内步数/可选节点，不动路由表与槽。
4. **可回退**：每批独立回退路径（git 还原 / 隔离区搬回 / config 一键拨回）；核心链默认档切换必须 A/B+目验双证。
5. **单人可维护**：宁可删不如修的项一律删；双轨一律并轨；不留「以防万一」的注释代码。
6. **估算口径**：人日 = AI 会话工作日（含实弹验证与写报告），非自然日承诺。
