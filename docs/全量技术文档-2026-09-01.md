## 1. 项目概述

### 1.1 是什么

OmniSpace 是**本地优先的全栈 AI 漫剧创作工作站**：对话 × 绘画 × 分镜 × 视频 × 语音 × 知识学习六大能力，全部推理在本地 GPU 完成，数据不出机器。交付形态 = launcher 守护进程 + 系统浏览器（Tauri 桌面壳已由 [ADR-002](ADR-002-tauri-shell-decision.md) 于 2026-08-20 裁剪）。

### 1.2 能力矩阵

| 模块 | 能力 | 前端入口 | 后端路由 |
|------|------|---------|---------|
| AI 对话 | 多模型流式对话、会话管理、RAG 注入、多模态（Qwen3-VL） | `/chat` → `components/dialog/` | `api/dialog.py`（24 端点） |
| AI 绘画 | 文生图/图生图/局部重绘/高清放大、ControlNet、LoRA、ComfyUI 双后端 | `/paint` → `components/paint/` | `api/draw.py`（27 端点） |
| 漫剧创作 | 分镜编辑器→资产库→关键帧→视频全链路（项目核心，见 §7） | `/storyboard` → `components/manga/` | `api/manga/`（91 端点） |
| AI 视频 | 图生/文生视频、镜头级生成与拼接（Wan2.2/LTX/H3） | 绘画页视频面板 + 漫剧视频列 | `api/manga/video.py`、paint I2V |
| 知识学习 | 文档向量化入库、RAG 混合检索、知识图谱、浏览器 Agent 自主学习 | `/learning` → `components/learning/` | `api/learning.py`、`api/knowledge.py`、`api/browser.py` |
| LoRA 训练 | 知识 LoRA / 视频风格 LoRA 增量微调、版本回滚 | `/style`、学习页训练区 | `api/learn.py`、`api/style.py` |
| 语音 | Whisper ASR、TTS 多引擎（CosyVoice/GPT-SoVITS/SAPI 回退）、音色克隆 | 漫剧音色绑定 | `api/voice.py`、`api/manga/voice.py` |
| 视觉工具（后端保留，**无前端入口**） | SAM 分割、MiDaS 深度、YOLOv8 检测、图生 3D（TripoSR .glb）——3D 导演台已于 2026-08-29 剔除；/art 六端点前端零调用，SAM 引擎另被漫剧 comic_gen 内部引用，其余挂起 | 无 | `api/vision_tools.py`（/art 前缀） |
| 模型管理 | 导入/校验/加载/卸载/切换/基准/VRAM 预估/模块选型 | `/models` | `api/models.py`（32 端点） |
| 系统 | 设置、备份、诊断、日志可视化、激活门禁 | `/settings`、`/logs` | `api/system.py`、`api/logs.py`、`api/license.py` |

### 1.3 硬件基线与性能锚点

- **产品硬件基线**：RTX 3060 12GB + 32GB RAM（入门档）；`HARDWARE_TIER_TABLE` 按 min_vram 分档路由模型，所有功能 MUST 在 12GB 档可用。开发实测机 RTX 5070 Ti 16GB。
- **2026-08-28 实测锚点**：对话 qwen3-vl-4b 首字 461ms；SDXL 768² 20 步 13.6s；wan22-ti2v-5b I2V 2s/720p 83.4s；后端冷启动 T+10s 就绪；vLLM 冷启动约 157s（由启动页阶段消化）。

## 2. 总体架构

### 2.1 五层架构

```
┌────────────────────────────────────────────────────────────────┐
│ 前端 SPA   React 19 + Zustand 5 + Tailwind 4（frontend/dist 同源托管） │
├────────────────────────────────────────────────────────────────┤
│ API 层    FastAPI 0.141，15 个路由模块 ≈320 HTTP（含别名）+ 4 WS    │
│           中间件链：CORS→限流→激活门禁→请求上下文→TrustedHost          │
├────────────────────────────────────────────────────────────────┤
│ 服务层    业务服务 + 推理引擎（services/inference/*） + 模型管理器      │
│           任务队列=进程内 PriorityQueue 四级（模拟 Celery 语义）        │
├────────────────────────────────────────────────────────────────┤
│ 资源层    engines/：GPU 后端选择、VRAM 记账、RAM 管理                  │
│           scheduler/：采样-决策-调度-协同分析闭环                      │
├────────────────────────────────────────────────────────────────┤
│ 数据层    SQLite WAL（31 用户表，user_version=7）+ ChromaDB 向量       │
│           + FTS5 全文 + 知识图谱轻量表 + 文件存储 + AES-GCM 字段加密    │
└────────────────────────────────────────────────────────────────┘
外部子进程：vLLM（py313 独立运行时，:8101）｜ComfyUI 便携版（:8189，Job Object 共生死）
```

### 3.2 应用装配与生命周期（main.py lifespan，按序）

1. 单实例互斥体 `single_instance.acquire()`（失败即拒启）
2. 激活门禁预热（指纹采集 + is_activated，失败不阻断启动）
3. 风格库加密种子首启动导入（style_seed）
4. 非回环绑定醒目告警
5. T+0s 数据库连通（`SELECT 1`）
6. T+3s 文件存储 + 缓存
7. T+4s 嵌入模型预加载（bge-large-zh 长驻 CUDA 低位显存段）
8. T+5s 资源调度引擎 start（不可用降级）
9. T+5.5s 浏览器进程池后台预热（headless）
10. T+5.8s 资源采样器 start（30s 采集 RAM/显存/磁盘）
11. T+6s WS 消息中枢 bind_loop + 注入广播器到 draw/lora_training/browser_agent/manga.common
12. 事件日志 30 天清理任务 + backend_started 事件
13. flow_trace 孤儿恢复（遗留 running→orphan）
14. 崩溃取证心跳（check_previous_crash + start，30s 刷新 logs/.heartbeat）
15. 视频任务遗留恢复（generating 全部改写 error）
16. 关闭序列：backend_stopped → heartbeat.stop → browser_pool.shutdown → ws_hub → scheduler.stop

### 3.3 中间件链（注册顺序即生效顺序）

`setup_cors`（仅本地来源 + ws_origin_guard 防 CSWSH）→ `setup_rate_limit`（300 req/min/端点，媒体回读独立桶 600/min）→ `license_gate_middleware`（未激活业务 API 全 403，白名单 /health、/api/v1/license）→ `RequestContextMiddleware`（request_id + duration_ms）→ `TrustedHostMiddleware`（仅 127.0.0.1/localhost/[::1]）。

异常处理器 4 个：ApiError / RequestValidationError / StarletteHTTPException（404/405 统一信封）/ Exception 兜底（写 unexpected_error 事件）。

### 3.5 统一响应信封与错误码（铁律）

```json
// 成功（HTTP 恒 200）
{"success": true, "data": {...}, "meta": {"request_id": "uuid", "timestamp": "ISO8601", "duration_ms": 12}}
// 失败
{"success": false, "data": null,
 "error": {"code": "MODEL_NOT_LOADED", "message": "...", "detail": {...}, "suggestion": "..."}}
```

错误码为语义串（约 100 个：MODEL_*/KNOWLEDGE_*/BROWSER_*/TRAINING_*/SYSTEM_*/FEATURE_*），历史数字码经 `_LEGACY_CODE_MAP` 自动映射。**suggestion 必须给出路指引，用 suggestion= kwarg，禁止塞进 detail。降级必须诚实：degraded:true + degrade_reason，禁止伪造结果。**

### 3.6 数据库设计

- **主库** `data/omnispace.db`：SQLite WAL，busy_timeout 10000，synchronous NORMAL，cache 16MB。FTS5 全文（trigram 中文 3 字滑窗 + BM25）。
- **用户表实测 32 张＝主库 30 张 + flow 独立库 2 张**（2026-09-01 只读实测校准；历史设计口径"31 张"漏计了实际存在的 paint_history，又误把 flow 两表计入主库。全字段清单见附录 B）：

  - 主库自建 12：behavior_logs、learning_settings、learning_topics、learning_sessions、learning_logs、knowledge_meta、style_tasks、model_benchmarks、api_keys、kg_entities、kg_edges、paint_history
  - flow 独立库 2（logs/flow_trace.db）：flow_executions、flow_nodes
- **迁移机制**：`PRAGMA user_version=7`，`_MIGRATION_GROUPS` 版本组 → ALTER TABLE ADD COLUMN（历史组禁改只许追加）+ `_DATA_MIGRATIONS`（v3 明文→加密 + VACUUM）；拒绝打开高于程序版本的库。表结构真源：`docs/design/database-er.md`。
- **字段级加密**（AES-256-GCM，前缀 `enc:v1:`）：dialog_messages.content 与 behavior_logs 四列（content/context/before/after）。密钥 32 字节经 DPAPI（CurrentUser）保护存 `data/keys/dbkey.bin`；DPAPI 不可用回退机器指纹 HKDK。知识库正文不加密（检索依赖明文）；整库为普通 SQLite 明文文件（SQLCipher 未启用，诚实标注）。
- **向量库**：ChromaDB（collection omnispace_knowledge，bge-large-zh 1024 维），不可用降级内存 TF-IDF 余弦。
- **模型注册表**：`data/model_registry.py` 只读消费 `models/models_manifest.json`（manifest v3 真源），做清单↔磁盘一致性；运行时显存权威在 model_manager.estimate_vram_gb。

## 4. AI 推理底座

### 4.1 模型管理器（services/model_manager/，ADR-003）

`ModelManager` 单例（`get_model_manager()`）：

## 5. 资源治理（GPU/VRAM/RAM）

### 5.1 阈值体系（真源 config.yaml scheduler.thresholds）

| 信号 | 阈值 | 动作 |
|------|------|------|
| 显存 | ≥80% / ≥90% / ≥95% | 警告调度介入 / 降精度+卸载非活跃 / 强制卸载 |
| GPU 利用率 | >85% 持续 5s / >95% 持续 15s | 轻度降参 steps×0.67 / 深度降档×0.4（4s 滞回） |
| GPU 温度 | ≥85°C / ≥90°C | 降频 / 强制暂停+拒绝新任务（feature_lock 层） |
| 空闲回收 | 60s / 300s | 浅回收（释放小模型）/ 卸载非驻留大模型 |

### 5.2 功能互斥与显存协商

- **互斥**（middleware/feature_lock.py）：dialog/paint/video_gen/training 进程内异步锁全互斥，冲突返回 FEATURE_MUTEX_LOCKED；≥90°C 拒绝新任务。前端导航置灰联动（FEATURE_SWITCH_RULES）。
- **生成期让渡三件套**（api/manga/common.py）：关键帧/视频生成持锁后 ① vLLM sleep_for_paint 让渡 ② 本地绘画管线卸载 ③ 收尾自动唤醒恢复。
- **模块切换**：前端切模块调 `/models/release-for-module` 兜底；进入 chat/paint 延迟 3s 点火 `/models/warmup` 预热 + 冷启动弹窗（DialogWarmupModal/PaintWarmupModal + 右栏常驻进度条）。
- **产品铁律**：模型未加载 → 立刻自动加载 + 进度弹窗 + 就绪后自动续跑（不许「再点一次」）；真失败才报错且必带 suggestion 出路指引。
- 周边守卫：quality_governor（在途降参）、thermal_guard（温度链）、resource_guard（RAM≤85%、VRAM≤90% 硬限）、scheduler/（monitor 分级采样 → decision 滞回 30s → dispatcher 真实动作 → analyzer 六种 SynergyMode 协同分析 → history 学习）。

## 14. 工程铁律与高频坑（实操手册）

**编码铁律**

1. 前端：.tsx、PascalCase、Omni 前缀、Function Component；Zustand create（禁 Context+useReducer）；CSS 颜色必须 var(--color-*)；禁 any（unknown+Zod）；useEffect 必须 cleanup；TS strict + tsc --noEmit 过再 vite build。
2. 后端：全函数 type hints；Pydantic v2 集中 data/models.py；asyncio 禁同步阻塞（唯一入口 services/offload.py run_blocking）；模型卸载三件套（del + torch.cuda.empty_cache() + gc.collect()）；引擎模块级懒加载单例；SQLite 写串行化；ruff check 过再提交。
3. 响应：HTTP 恒 200 + 信封；错误码语义串；suggestion 必带出路；降级必须诚实 degraded:true。
4. 提交规范：type(scope): description（feat/fix/docs/style/refactor/test/chore）。

**高频坑（历次实测教训）**

- **端口**：新链 boot.py 默认 5800-5835；旧链 8765 严禁同机双跑（显存叠载：关键帧采样 20+ 分钟超时、08-29 蓝屏同源）。
- **重启纪律**：后端改码必须重启后端；前端改码必须构建（tsc+vite build）+ 真浏览器实测再汇报（用户可能手动回退源码致 dist 不同步）。
- **测试拉实例**：必须 Start-Process 脱离会话启动（bash 后台任务会被清理杀进程树）；stdout 落文件；stop.py 扫全部 boot 慎用于测试。
- **热门文件编辑前先重读**（并发会话实况）。
- **grid 容器加 max-height 必须配 grid-auto-rows:max-content**（否则 511 卡摊成 2px 纸片）；装饰 flex 子项必须 basis:0。
- **VLM 会幻觉布局问题：以 Playwright 量 DOM 为准**；mock 缓存 HTML 须重启。
- **minify 中转 \uXXXX：grep 中文无命中 ≠ 构建失败**。
- **SQLite insert 多塞非表列会静默降级内存库**（不报错）。
- **前端 data 是 dict{groups,models,total} 不是数组**（模型导入接口）。
- **对话下拉受「范围」白名单拦截是设计内**；ApiError 指引必须用 suggestion= kwarg。
- **漫剧 asset_ids 是真源**，名称列常空；僵尸 video worker 只能重启收割。
- **翻译等轻推理必须先于 ensure_loaded**（否则驱逐绘画模型）。
- **首帧 elapsed 须钳非负**；paint 无 loading 态已补，新链路注意。
