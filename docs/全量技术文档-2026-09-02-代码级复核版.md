## 一、项目是什么（一句话 + 真实能力边界）

**OmniSpace＝一台跑在用户本机（Windows + 单 NVIDIA GPU）的本地 AI 工作站**：FastAPI 后端 + React 单页前端同源托管 + 多个 AI 引擎子进程（vLLM / ComfyUI / llama.cpp），围绕「对话 / 绘画 / 漫剧（分镜→关键帧→视频）/ 知识学习 / 视频风格 LoRA / 语音」组织成 9 个页面，正冲刺桌面软件封装发行。✅（架构证据见 §3/§6/§8）

**能力公式（对外宣称「六模态」）**：对话 × 绘画 × 分镜 × 视频 × 语音 × 知识学习。✅ 模块全在（main.py:263-279 共 15 个 API 模块）；但两条要打折扣：
