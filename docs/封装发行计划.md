## 一、一页总览

**卖什么**：一个 ≤50G 的桌面软件包（实测 ~22.4G 🔶模拟值待实包复核）+ 一份约 260G 的大模型包（用户自行获取放入）。
**买家体验（09-02 用户定稿公式）**：安装软件 → 把大模型文件夹 **models 拖入软件**（拖桌面图标 / 拖安装目录 / 启动页拖放卡，三通道见 §2.4）→ 启动软件 → **首启输激活码**（仅第一次启动需要；license.bin 落盘后后续启动自动放行，boot.py:737-745 已实现）→ 完美使用全部功能。一次启动内完成，不再要求「退出软件再放模型」。
**怎么收钱保护**：激活码（Ed25519 离线验证，未激活全 API 拦截 ✅ 已实测）+ 客户水印（泄露溯源）+ 源码 Cython 加壳 + 双哨兵。
**当前进度**：打包管线底座 ✅ 建成；白名单已按新政策改造 ✅；模型挂接理论验证 ✅ 三章；**启动页激活面板已现成 ✅（splash.html:499-514 指纹复制+激活码输入+激活按钮，boot 未激活不放行）**；**挂接器核心+拖入接线已落地 ✅（09-02 晚：comfy_mount.py 单测 9/9+开发机实弹对账 16/16 已就位零改动；comfy_proc 拉起前自动重挂；boot 拖入识别通道 A/B，顺手修复「拖入参数致 argparse 报错」炸点；make_dist 哨兵收编）**；余：跨卷 yaml 降级（2b）、就绪总检引导页（#3）、通道 C、实弹重启窗口验证；桌面壳 S0 ✅ / S1~S4 待建。

## 二、产品形态（09-02 三次演进后的定稿）

演进轨迹：全家桶 272G（早）→ 纯软件 6.5G+全外置（晚）→ **≤50G·大模型外置·其余内置（深夜定稿）**。

### 2.1 软件包（~22.4G，枚举模拟实测 🔶，正式构建以实包复核）

| 构成 | 体积 | 状态 |
|---|---|---|
| 双 Python 运行时（3.10 主程序 + 3.13 vLLM） | 10.7G | ✅ 白名单既有 |
| ComfyUI 引擎（程序+运行时+全部自定义节点+引擎小件 vae_approx/configs/embeddings） | 5.5G | ✅ 过滤规则已改（09-02，单测 8/8） |
| 依赖库 pydeps（已剔 ~110M 无用件） | 1.6G | ✅ 既有 |
| **内置辅助件**：SAM 2.4G / 检索 bge 1.2G / 人脸一致性 0.5G / whisper-tiny 0.1G | 4.2G | ✅ 白名单已加（09-02） |
| 后端（构建时 Cython 加壳+公钥注入）/ 壳 / 前端 dist / ffmpeg | ~0.4G | ✅ 既有 |
| 加密资产：工作流模板+画风种子（构建时加密入 assets_enc，包内明文即灭） | 小件 | ✅ 机制已建 |

**不内置**：models/lora（学习页训练产物区，用户数据，首启自建）；paint/loras 等 klein 配套（随大模型包，避免双份）。

### 2.2 大模型包（~260G，用户自装，渠道用户自理）

内容=除内置件外的 models/ 全部：klein 全家（9b/9b-fp8/4b）+ qwen-image + H3 全家（含 09-02 安家的 ref2va 19.5G + turbo lora 0.73G）+ 对话三模型 + sdxl/sd15 + paint·loras。目录契约=两层结构 `models/<分类>/<名字>/`（夸克上传结构即范本）。

### 2.3 「即插即用」机制（理论验证三章定案，报告=docs/模型即插即用-多轮理论验证-2026-09-02.md）

- **主方案**：同卷硬链自动挂接——挂接器按 comfy_model_map.json（现为 16 行，双侧 inode 全对账 ✅）在 ComfyUI 拉起前重建门牌；幂等判据=**两端同 inode**（防「删后重放」版本漂移，实测实锤）；
- **辅助**：跨卷/外部路径降级 extra_model_paths.yaml（引擎 v0.34.0 支持 📖 main.py:141；不能改名，受文件名契约约束）；
- **否决**：复制（244G 双倍占盘）；
- 时序：ComfyUI 进程内列表缓存存在 📖 → 挂接在拉起前执行即无死角；引擎运行中拖入的新模型下次冷启生效（契约写明）。

### 2.4 「拖入 models → 启动 → 启动页输激活码 → 即用」接线设计（09-02 体验流定稿配套）

**用户公式拆成四个环节，逐环节对照代码现状：**

| 环节 | 方案 | 现状 |
|---|---|---|
| ① 拖入 models | 三通道（下表），全部汇入挂接器 | 🔶 挂接器待建；通道 A/B 零代码；通道 C 有载体（splash）无拖放卡 |
| ② 启动软件 | boot 五阶段点火（splash→env→backend→warmup→ready） | ✅ 现成（boot.py:832-882） |
| ③ 启动页输激活码 | splash P7 激活面板：指纹复制（splash.html:511）+ 激活码输入框（:512-513）+ 激活按钮 POST /api/v1/license/activate（:991）；boot license 阶段未激活不放行自动进入（boot.py:737-745）；主界面另有 LicenseGate 全屏遮罩兜底（App.tsx:442） | ✅ **已现成**；仅差壳 S1 集成 |
| ④ 完美使用 | 模型就绪总检+引导页显示各模块就绪；缺什么指到哪 | ✅ **已落地（09-03）**：backend readiness.py+GET /models/readiness（单测 7/7；开发机实弹 7 模块全绿）+模型管理页 ReadinessBanner 横幅（绿勾/灰圈+缺件指路）；**生效须后端重启**；首启全屏引导页留迭代 |

**拖入三通道（按「小白友好度×技术可靠性」排序）：**

| 通道 | 交互 | 技术机制 | 可靠性/约束 |
|---|---|---|---|
| **A. 拖到桌面图标/启动 exe 上（主推）** | 把 models 文件夹拖到「启动OmniSpace」图标 → 软件自动带着路径启动并进入「模型导入模式」 | Windows 原生行为：拖文件夹到 exe/快捷方式＝以该路径为 argv 启动；exe 桩（omnispace_exe.c）→boot.py 解析 argv[1]→识别（找 models_manifest.json 或两层结构）→splash 显示「模型接线中」→挂接器执行→完成后继续点火 | 100% 系统原生；**时机完美＝启动前拖入，ComfyUI 必未拉起，挂接无死角**；跨卷源需降级（见下） |
| **B. 拖进安装目录收件箱（保底）** | 打开安装文件夹，把 models 拖进去（同名合并） | 发行包内置空 models/ 骨架（分类子目录+「把大模型放这里.txt」指引）；boot 启动时检测 models/ 内容变化→触发挂接 | Explorer 级拖放对 260G 同盘移动＝秒级；已有契约（两层结构、建议合并不删目录） |
| **C. 启动页拖放卡（UI 化）** | 引导页一张「把 models 文件夹拖到这里」卡片 | **技术真相：WebView2/浏览器 HTML5 drop 出于安全拿不到文件夹绝对路径**（只有文件夹名+可递归读条目，260G 不可行）。可行实现＝drop 取文件夹名→后端扫描各盘/下载目录/安装目录找唯一同名匹配→确认卡「找到 D:\models（约 N G），开始接线？」；找不到→「浏览选择」按钮弹原生目录选择器（boot 侧纯 ctypes，嵌入式运行时无 tkinter） | 兜底体验通道；引擎运行中拖入＝下次冷启生效（契约已有） |

**同卷/跨卷决策树（挂接器内建）：**
1. 模型与软件同卷 → 硬链挂接（零拷贝，幂等判据=两端同 inode）——主方案；
2. 跨卷 → 优先提示「建议先把 models 文件夹移动到安装盘（同盘移动瞬间完成）」；
3. 用户坚持跨卷 → **已落地（09-03）三级降级**：平同名条目走 extra_model_paths.yaml 零拷贝（引擎原生 `--extra-model-paths-config`，yaml 落 data/）；改名/子目录形状小件（≤1GB，实map 仅 klein vae 161MB 与 insightface 五件）拷贝进门牌位；超限列无解并指路移盘。后端侧由启动期按外部 manifest 幂等回填 file_path（boot 写 marker → external_bootstrap）。**移盘回同卷后自动撤销降级回硬链正轨**。

**激活段细节（发码台侧，均已实测 ✅）**：客户在启动页点「复制本机指纹」→ 发给卖家 → 卖家在发码台（127.0.0.1:7523）按指纹发码（Ed25519，3 指纹 3 中 2 容错换硬件）→ 客户粘贴激活 → 验签通过落 data/license.bin → boot 放行 → 全功能。买断制无时限；错码/他机码实测被拒。

**「完美使用」的验收口径＝就绪总检**：按 models_manifest v3（19 条目）逐项检查盘上存在性+目录大小合理性 → 模块级汇总（对话/绘画/漫剧关键帧/漫剧视频/知识库/语音）→ 引导页绿勾/置灰+缺件指路 → 就绪后全自动续跑（「未加载必须全自动」铁律同源）。总检与出门闸门 #5（白机终验）同一套判据。

## 五、用户端体验流（2026-09-02 用户定稿公式，唯一口径）

**一句话**：装软件 → 把 models 大模型文件夹拖入软件 → 启动 → **首启**输激活码 → 完美使用。

1. 安装/解压软件包（≤50G）→ 桌面出现「启动OmniSpace」图标；
2. **拖入 models**（三通道任选，§2.4）：拖到桌面图标上（推荐，软件带着模型路径自动启动并接线）／打开安装文件夹把 models 拖进去／先启动后在引导页拖放卡选择；
3. 启动页（splash HUD）：先「模型接线中」（识别→校验→挂接→登记，通道 A/B 自动触发）→ 到激活卡：点「复制本机指纹」发给卖家 → 收到激活码粘贴 → 激活（Ed25519 离线验签，错码即拒）；
4. 激活通过自动放行 → 后端就绪 → 主界面，引导页/顶栏显示**模型就绪总检**（对话/绘画/漫剧关键帧/漫剧视频/知识库逐项绿勾；缺件置灰+指路）；
5. 全功能可用。内置能力（知识库/检索/一致性度量/whisper 转写）不依赖大模型包，激活后立即可用。

**与旧公式（09-02 晨）的差异**：旧版要求「首启激活→**退出软件**→放模型→**再启动**」；定稿版把拖入放在启动前（通道 A/B）或并入同一启动（通道 C），**一次启动闭环**，时机天然满足「挂接在引擎拉起前」铁律。
