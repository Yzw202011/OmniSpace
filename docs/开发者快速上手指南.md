## 1. 硬件与系统要求

| 档位 | 配置 | 能做什么 |
| --- | --- | --- |
| 无 GPU | 任意现代 PC | 后端逻辑 / 单元测试 / 前端 UI / 文档；AI 生成功能不可用（可在设置页填自己的云端 API Key 部分替代） |

- **显卡驱动**：需支持 CUDA 12.x 的较新驱动

## 2. 开发环境搭建（逐步）

### 2.1 安装基础三件套

1. **Git**：任意近期版本。
2. **Python 3.10.11**（版本锁死，请勿用 3.11+，部分钉版依赖装不上）：[python.org 下载 Windows installer](https://www.python.org/downloads/release/python-31011/)，勾选 *Add to PATH*。
3. **Node.js 20 LTS**（开发机实测 v20.20.2；pnpm 版本由 frontend/package.json 的 `packageManager` 字段钉死为 pnpm@11.22.0）。

### 2.2 克隆 + 启用提交钩子

```powershell
git clone https://github.com/Yzw202011/OmniSpace.git
cd OmniSpace
git config core.hooksPath .githooks   # 每台开发机执行一次，启用提交四闸
```

提交钩子四闸（`.githooks/pre-commit`）：**compileall 语法基线 → ruff 静态检查 → pytest -m smoke 冒烟 → mypy 增量检查**（mypy 基线冻结于 `tools/mypy_baseline.txt`，只增不减）。

> ⚠️ **诚实说明**：钩子脚本查找 `runtime/py310/python.exe` 与 `tools/ruff/ruff.exe` 这两个固定路径，**找不到会打印提示后自动跳过该闸**（集成机便利设计，不是静默放行——跳过时有输出）。想要四闸在你机器上真实生效，用 §2.3 方案 B。

小贴士：本仓库有大量中文文件名，git 默认把它们显示成八进制转义码。建议随身配置一次：
```bash
git config --global core.quotepath false
```

### 2.3 Python 后端环境（二选一）

**方案 A：常规 venv（最简单，推荐先用这个跑通）**

```powershell
py -3.10 -m venv .venv
.venv\Scripts\activate
python -m pip install -U pip
pip install -r requirements-lock.txt --extra-index-url https://download.pytorch.org/whl/cu128
```

- **为什么必须加 `--extra-index-url`**：锁定文件钉的是 `torch==2.11.0+cu128`（requirements-lock.txt:161），带 `+cu128` 后缀的构建**只在 PyTorch 官方源**存在，不加这个参数会装成 CPU 版或直接解析失败。
- ruff / mypy 不在锁定文件里，单独装：`pip install ruff mypy`（装进 venv 后激活状态下钩子/命令即可用）。
- ⚠️ 已知版本漂移：开发机实装 torch 为 2.13.0+cu130（比 lock 新，两者都与 CUDA 12.x 驱动兼容）。如果你是 50 系显卡（sm_120），cu128 轮子不支持，需自行 `pip install torch==2.13.0 --index-url https://download.pytorch.org/whl/cu130` 并同步 torchaudio/torchvision。

**方案 B：装到仓库约定路径，让钩子/测试脚本全自动生效（可选）**

仓库的钩子和 `tools/run_tests.py` 硬编码找 `runtime\py310\python.exe`。官方安装器装出来的目录根部本来就有 python.exe，所以直接：

```powershell
# 用官方 Python 3.10.11 安装器，自定义安装路径选 <仓库根>\runtime\py310
runtime\py310\python.exe -m pip install -r requirements-lock.txt --extra-index-url https://download.pytorch.org/whl/cu128
pip install ruff mypy   # 同样装进这个解释器
```

（`runtime/` 已在 .gitignore，不会污染仓库；此路径 = 本项目"内嵌运行时"的约定位置。）

**验证后端环境**：

```powershell
python -c "import fastapi, torch, diffusers; print(torch.__version__, torch.cuda.is_available())"
# 预期：2.x.x+cu1xx True（无 GPU 机器 False 属正常）
```

### 2.4 前端环境

```powershell
corepack enable                 # Node 20 自带 corepack；自动按 packageManager 字段用 pnpm@11.22.0
cd frontend
pnpm install
pnpm dev                        # 开发服务器 http://localhost:5173
```

- vite 已配置代理（frontend/vite.config.ts:33）：5173 页面的 `/api`、`/ws` 请求自动转发到 `http://127.0.0.1:5800`，**必须先把后端跑起来**（§2.5）。
- 生产形态构建：`pnpm build`（含 tsc --noEmit 类型闸），产物 dist/ 由后端自动托管。

### 2.5 启动联调（无 GPU、无模型也能跑）

**后端**（⚠️ 必须以仓库根目录为 cwd，相对路径全部依赖此约定）：

```powershell
.venv\Scripts\activate          # 方案 B 则跳过激活，直接用 runtime\py310\python.exe
python -m uvicorn backend.main:app --host 127.0.0.1 --port 5800 --reload
```

- 首次启动自动创建 `data/`（SQLite WAL 主库 + ChromaDB + 文件存储），**无需任何数据库安装**
- 启动自检（backend/startup_check.py 26 项）会报若干 warn（模型未就位等）= 正常，不拦启动
- 健康确认：浏览器开 `http://127.0.0.1:5800/health`，或 `GET /api/v1/system/health-check`（一键体检，自愈批4）
- **单实例互斥**：Windows 命名互斥体，重复启动第二个后端会立即失败并给出指引（豁免：pytest 运行态 / 环境变量 `OMNISPACE_ALLOW_MULTI=1`）

**前端**：`pnpm dev` 后浏览器开 http://localhost:5173 —— 能看到聊天/漫画/漫剧页面即联通。

**两种页面打开方式**：
- 开发态：5173（vite 热更新，代理到 5800）
- 生产态：`pnpm build` 后直接开 `http://127.0.0.1:5800`（后端托管 dist）

**贴近真实用户体验的启动**：`python launcher\launcher.py`（launcher 守护进程默认 :8765，冲突时扫描 5800-5835 递进；含启动页 HUD）。日常开发用 2.5 开头的 uvicorn + vite 即可。

### 2.6 （可选）完整 AI 功能环境

| 组件 | 用途 | 怎么装 |
| --- | --- | --- |
| FFmpeg | 视频编码/拼接 | 放 `runtime/ffmpeg/bin/ffmpeg.exe`，或 `tools/downloads/`，或系统 PATH（发现顺序见 backend/services/encoder_service.py:175） |
| ComfyUI 便携版 | 绘画/关键帧/视频的本地推理后端（端口 8189，由后端托管生命周期，空闲 300s 自动关闭） | 惯例路径 `tools/ComfyUI_windows_portable/`；体量大、结构有约定，**建议先联系维护者同步目录**，勿自行裸装 |
| 模型权重 | 对话/绘画/视频/检索全功能 | **权威表 = [deployment-manual.md](deployment-manual.md) §3 模型资产配置表**（manifest v3，20 项）；最小可跑集（对话+绘画+视频）≈55G：qwen3-vl-4b + flux2-klein-9b + AnimateLCM + sd15 + 小模型组 |
| 云端 API（可选） | 无本地模型时部分替代 | 设置页填自己的 Key（如 DeepSeek 文本），本地 AES-256-GCM 加密存储 |

模型放置说明：目录约定 `models/<模型名>/`。你的机器上没有 `models/models_manifest.json`（它随模型目录走，不入仓库），首次启动自检第 25 项会给警告；用**模型管理页（/models）的导入功能**扫描登记即可，或按 deployment §3 手工对齐目录名。

> vLLM 对话引擎（可选加速档）运行在独立的 Python 3.13 子进程环境（实装 vLLM 0.27.1），不装不影响——对话自动走 Transformers/GGUF 档并如实标注。

## 3. 测试体系（三层）

```powershell
# L1 后端单元/冒烟（离线可跑，GPU 集成显式开关默认关）
python -m pytest backend/tests -q                 # 全量
python -m pytest backend/tests -m smoke -q        # 提交前最小集

# L2 前端 vitest（store / Zod schema / 枚举一致性 / 错误策略扫描）
cd frontend && pnpm test

# L3 活后端 E2E 流程编排（需先启动 5800 后端）
python tools\run_tests.py --e2e
```

- `pytest.ini`：只收集 backend/tests；根目录 tests/ 是活后端流程编排脚本（不进 pytest 收集，见 tests/README.md）
- 统一入口 `tools/run_tests.py`（--smoke / 默认 L1+L2 / --e2e）⚠️ 该脚本硬编码 `runtime\py310\python.exe`——用方案 A venv 的同学请直接用上面的 pytest/pnpm 原生命令
- 基线（2026-09-11 静态统计）：后端 693 个测试函数、前端 75 个用例

## 4. 代码规矩（摘要，全文必读 [CLAUDE.md](../CLAUDE.md)）

**后端（Python 3.10）**
- 全部函数写 type hints；API 数据模型一律 Pydantic v2（集中在 backend/data/models.py）
- asyncio 内禁止同步阻塞（一律走 services/offload.py）；SQL 只参数化；SQLite 写串行化
- API 响应信封恒 200 + `success/data/meta`，失败 `error.code/message/suggestion`（**错误必须带出路建议**）
- 降级必须诚实：不可用返回 `degraded:true + degrade_reason`，禁止伪造结果

**前端（TS strict）**
- 禁 `any`；新接 API/WS 入口一律 Zod `.parse()`（模板 = frontend/src/services/schema.ts）
- CSS 颜色只用 `var(--color-*)`（令牌权威源 frontend/src/styles/tokens.css；主题族定义文件豁免）
- AI token 流一律 SSE，WS 只做状态广播

**红线（违反 = 打回）**
- `VIDEO_ROUTING_TABLE` / manga-video 槽 / H3 条目不动（漫剧视频主力锁定）
- `packaging_console/`、`license_console/` 代码冻结且**不在本仓库**（内部工具）
- 不擅自新增第三方依赖；改核心链路（模型加载/队列/调度/DB 迁移）先走方案四段制
- 提交信息格式：`type(scope): description`（feat/fix/docs/refactor/perf/chore/style/test）

## 5. 常见问题速查

| 症状 | 原因与出路 |
| --- | --- |
| pip 装出 CPU 版 torch / 报找不到 +cu128 | 忘了 `--extra-index-url https://download.pytorch.org/whl/cu128`（§2.3） |
| 提交时钩子显示"跳过检查" | 没有按方案 B 放置 `runtime\py310\python.exe` / `tools\ruff\ruff.exe`；要真实四闸见 §2.3 |
| 后端秒失败退出 | 单实例互斥：已有一个后端在跑（任务管理器找 python/uvicorn），或端口被占 |
| 前端 5173 页面 API 全 404 | 后端没起 / 没在 5800（代理目标见 frontend/vite.config.ts:38） |
| 启动自检一堆 warn | 模型未就位、manifest 缺失属预期；影响启动的硬错误会单独 FATAL |
| mypy 提示"存量 N 条冻结于基线" | 基线只增不减：你的新代码必须零新增；本地自查 `python tools/run_mypy.py --staged` |
| git 显示中文文件名乱码 | `git config --global core.quotepath false`（§2.2） |
| 端口约定总览 | 后端 5800（config.yaml）/ launcher 8765（冲突扫 5800-5835）/ ComfyUI 8189 / 前端 dev 5173 |
| 数据库 user_version 报错 | 见 [troubleshooting.md](troubleshooting.md)（迁移组机制，禁手改） |
