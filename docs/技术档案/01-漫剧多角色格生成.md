## 二、引擎自动选路（✅keyframe.py:1240-1258）

`engine="auto"` 时全部满足才走 comfy+PuLID 硬锁道：
1. 环境变量 `OMNI_KEYFRAME_PULID_AUTO != "0"`
2. `comfy_paint_available()`（便携版+权重在位）
3. `pulid_available()`（PuLID 节点/权重就绪）
4. 绑定角色数 1~2（**chars≥3 维持 diffusers**——参考稀释风险，2026-09-10 UAT 裁定）
5. 至少一个角色有面部参考（InsightFace 可稳定检测）

route_label 四态：`comfy+双PuLID`（chars=2 且双 face 齐备）／`comfy+PuLID`（单角色）／
`comfy+多参考`（软锁回落）／`diffusers`。

## 三、身份一致性：双硬锁协议（✅keyframe.py:1053-1061）

- chars=2 且 face_refs[0]、face_refs[1] 均非空 → (faceA, faceB) 按绑定序注入
  双 PuLID（ApplyPuLIDFlux2 双实例）；face_refs 与 char_assets **同源同序**
  （P0-3 协议，错锁防护依据，keyframe.py:1056-1057）。
- 单/缺 face → 多参考软锁（ReferenceLatent latent 级传递）。
- face 列只在转全局时落库，项目资产按所属项目 project_type 判定
  （comic_asset.py:522 _face_of_project；序列化默认 face='manga' 是显示层兜底）。

## 四、并发与锁（✅）

| 机制 | 位置 | 语义 |
|---|---|---|
| paint 功能锁 | middleware/feature_lock.py（域互斥） | 队列排空循环持有；锁持有中守卫/深层回收跳过活动类别 |
| 图像队列 | services/image_queue.py:11,95 | 单 daemon worker FIFO；取消=排队剔除/运行中协作中断 |
| vLLM 让渡 | models.py:1428 | 队列准入时睡眠 vLLM 释放 ~9GB；排空 10s 无新任务唤醒（gpu_budget:603） |
| comfy 反向互斥 | keyframe.py:1263-1266 | diffusers 道先卸 ComfyUI 驻留权重；反之 comfy 道卸本地管线（keyframe.py:1261） |
| 生成毕卸载 | keyframe.py:1751-1756 | comfy 权重即卸（进程保活）——一致性守卫需唤醒 vLLM 评分，两族 ~10GB 不可同驻（V40 事故） |
