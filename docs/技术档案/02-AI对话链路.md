## 二、模型档位与自动降级（✅）

- 候选表 HARDWARE_TIER（data/models.py:122-123）：`qwen3-vl-8b-awq min_vram 12GB`、
  `qwen3-vl-4b min_vram 8GB`；`_effective_candidates()`（dialog_engine.py:371）
  按当前空闲显存筛可装档。
- 装不下首选 → 自动降级次档：`_degraded_from` 状态（dialog_engine.py:697）→
  WS 广播 `model_fallback` + 事件 `dialog/model_tier_autoselect`（大白话
  "8B 装不下已自动选用 4B 档"）→ 前端气泡「（自动降级）」徽标。
- 思考模式：`thinking` 请求位 → max_new_tokens ≥2048（dialog.py:760-761）；
  reasoning 与正文分通道推送（{"reasoning"} / {"token"}，dialog.py:930-932）；
  原生思考后端（vllm/gguf/llama）不再注入四步思考框架（dialog.py:826-835，
  09-10「你好→一大段无关」双根因修复之一）。

## 四、知识注入（RAG）与反馈闭环（✅）

- 双路召回：向量（ChromaDB bge）+ 关键词（FTS5）→ RRF 融合（k=60）→
  向量分地板 `MIN_VECTOR_SCORE=0.55` 过滤（injection_service.py:40,152-154）
  → 创作意图降权（方法论类优先+条数收敛 3，injection_service.py:43-46,242-246）
- 注入模板=参考资料制（09-05「写剧本只回 10 字」事故根修 17d186f，
  injection_service.py:217-225）
- 引用落库 `dialog_messages.rag_refs`（database.py:64，schema v8 迁移 :550）
- 反馈闭环：对话页 👍/👎 → adjust_quality_score（踩 -0.8/赞 +0.2，clamp ±1）
  → 负分条目注入时跳过（_is_demoted，injection_service.py:159-173）

## 五、数据与安全（✅）

- 表：`dialog_sessions`（database.py:44）、`dialog_messages`（:55；
  content 列 **AES-256-GCM 字段级加密**（crypto.py:15）+ rag_refs JSON）
- 附件：图片 base64 直传；文档经 /dialog/parse-document（.docx，20MB 上限、
  .doc 老格式诚实拒绝——09-11 实测记录）
- 输出契约：SSE 事件序 session_id → knowledge_refs? → token* → meta → [DONE]
  （dialog.py:917-921）；错误帧 {"error","code"} 后 done 收尾

## 六、配置项（✅config.yaml）

`dialog.max_context_tokens=8192`、`dialog.max_input_chars=32768`、
`dialog.stream_chunk_size=4`（WS 每 4 token 一帧）、
`scheduler.dialog_idle_unload_seconds=900`；请求级 temperature=0.7 /
max_new_tokens=1024 缺省（dialog.py:752-759）。
