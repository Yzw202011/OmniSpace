## 〇、原著深读与设计转译（2026-09-11，v1.3 新增）

### 0.1 四维调研结论

**① 故事背景**：原著为超级大坦克科比（王金星）的都市写实小说（番茄评分 9.4，与《我的26岁女房客》《我的郁金香小姐》并称三部曲），掌阅科技 2026 年改编为同名实景短剧（红果/抖音开播，播放量超 8.3 亿）。时代底色是当代都市青年的精神困境——原句：「上海也好，大理也罢，城市里灯火通明，孤寂的却只有人心」。主角米高在上海失意（情变、挚友离世），带着友人遗愿逃离上海奔赴大理。作者写书前亲历大理开客栈，在地生活质感极浓。

**② 故事地点**：双城结构——上海（失意之地，冷）⇄ 大理（治愈之地，暖）。大理侧实打实的地名与场景：**龙龛**（洱海边白族村落，米高第一间客栈所在，拆迁冲突发生地）、九隆居、大理古城、洱海沿岸、苍山脚下、特色街巷与山间民宿。「风花雪月」在书中有双重身份：既是四景，也是**客栈之名**。

**③ 故事叙事**：写实主义；双城对照叙事（都市喧嚣孤寂 vs 大理风花雪月）；独白体语感；情感双线——米高×叶芷（主线的遗憾与退出：分手是为了保护对方、滚石坠下先救别人、含泪离场）+ 米高×杨思思（陪伴与守候）；结局留白：风花雪月客栈开着，米高心里等的是叶芷，孩子暗示未点破。**「等」是书眼**。

**④ 故事内容**：主题四词——逃离都市、寻找自我、治愈成长、情感纠葛。内核是「苦底甜面」：虐心的底层，治愈的表层，媒体评「在大理的实景里，给都市人一碗『慢熬』的治愈鸡汤」。核心意象 = **客栈**：既是营生，更是「等」的空间装置——灯亮着，人就有处可回。

### 0.2 设计转译（从作品到主题的映射）

| 作品要素 | 设计转译 | 落点 |
|---|---|---|
| 客栈灯火=「等你」的具象 | **暖灯火色成为 A 方案主色**（灯笼橘金，取代原「月光金」——月是四景，灯是人心）；场景里**苍山脚下一间亮着窗灯的小客栈剪影** | 色板 A + 预览场景 |
| 双城对照（冷都/暖乡） | 暗色 = 暮蓝夜 × 地平线一线黄昏余温；**冷暖同框**而非纯冷夜 | 场景 sky 渐变 |
| 白族在地文化（龙龛白族村、扎染、白墙青瓦） | **扎染靛蓝**入色板第三色；亮色「苍山雪」底改**白墙暖白**（不是冷雪白） | 色板两版 |
| 苦底甜面、写实不甜腻 | 全局饱和度压低一档，暖色不糖；夜色保留静谧的蓝 | 色板整体 |
| 「等」是书眼 | 对话页主文案改写：「灯还亮着，就等你回来」；四句植入不变（§1.5） | 文案层 |
| 四景仍是骨架 | 洱海月/苍山雪 两模式命名不变；下关风动效、上关花茶花粉不变 | 整体结构 |

> 结论：v1.2 预览的「月夜山水」是**景**，作品要的是**人**——本版把场景从风景画改成「有人间灯火的水墨夜」，A/B 两案分别对应书中两味：**A 灯火茶花（书中的人情·暖）／B 青玉月白（景中的留白·素）**。
> 需求原话：治愈系——上关花，下关风，苍山雪，洱海月，「我在风花雪月里等你」；
> 启动页联动——「以后选择主题并保存，下次启动，启动页也会相应变化」。

## 一、主题设计（这是「设计」部分）

### 1.1 命名与身份

| 项 | 值 | 依据 |
|---|---|---|
| 主题族名 | **Dali**（大理） | 沿用专有名词族名惯例（Sakura / Nebula） |
| 暗色模式 | **Dali · 洱海月**（值 `dali`） | 现有四主题均为「族名 · 双字mode」格式 |
| 亮色模式 | **Dali · 苍山雪**（值 `dali-light`） | 同上（Nebula · 深空/晨辉 同构） |
| 挂载契约 | `<html data-family="dali">`（+`data-theme="light"` 为亮色） | 与 tech 族同构（useAppStore.ts:22,49-55） |

**四景各就其位**（风花雪月不是四个颜色，是四层设计语言）：

| 一景 | 落位 | 说明 |
|---|---|---|
| **洱海月** | 暗色模式的底色与主色 | 洱海夜色做画布（青蓝湖水底），月光做主色（暖月金）——「月照湖面」就是暗色主题本身 |
| **苍山雪** | 亮色模式的底色 | 雪雾白做画布（微青调雪白），苍山黛做文字——「雪后初晴」就是亮色主题 |
| **上关花** | 辅助色（两模式共用） | 上关名产山茶花 → 柔和茶花粉做 accent，用在选中态/徽章/高亮 |
| **下关风** | 动效层（主界面 + 启动页共用语言） | 风是动不是色：风絮缓漂、月晕呼吸、湖光扫过，全部低速度低透明度——「治愈」的体感来自这里 |

宣传语「我在风花雪月里等你」落在设置页主题卡片描述文案（零组件改动）。

### 1.5 四句植入各功能页（D4 已拍板：拆句 + 艺术字 + 文字背景 + 若隐若现）

宣传语拆开，一句一景一功能，做页面级**背景艺术字水印层**：

| 功能页 | 植入句 | 意象理由 |
|---|---|---|
| /chat 对话 | **我在风花雪月里等你** | 等你 = AI 伙伴在对话页等你回来，全句给最重要的相遇处 |
| /paint 绘画·漫画 | **上关花** | 画布开花，创作从一朵花开始 |
| /storyboard 漫剧创作 | **洱海月** | 银幕如湖面，月色即影像 |
| /learning 学习 | **下关风** | 知识如风，流动不息 |
| /models 模型管理 | **苍山雪** | 雪冠苍山 = 沉稳精密的底座 |

艺术处理（全族作用域 CSS + 一个小组件，仅 Dali 族可见）：
- **艺术字**：楷体族（KaiTi/STKaiti 兜底 serif），竖排（writing-mode: vertical-rl），大字号（≈10vh），宽字距——立轴水墨气质；
- **文字背景**：每句一景的极淡渐变晕染垫底（花=茶花粉晕、风=湖青风痕、雪=冷白霜光、月=月金月晕），位置各页错落（左/右轮换，不挡内容）；
- **若隐若现**：透明度 0.04↔0.10 缓慢呼吸（12~16s 循环，只动 opacity），粒子同频明灭；
- **不挡活**：`pointer-events: none` + z-index 压在内容层之下；设置/日志/帮助等功能页不植入（工具页保持素净）；亮色模式同句同位，晕染色换浅调。

### 1.4 启动页联动（v1.1 新增）

**联动链路**（一处保存，两处生效）：

```
设置页/顶栏 setTheme ──► localStorage（现有，即时生效）
                    └─► fire-and-forget 全量 PUT /system/settings {…当前设置, theme}
                          └─► backend 落 system_settings 表（KV，key='system.settings'）
下次启动：boot.py 只读 SQLite 取 theme ──► 往 splash.html <html> 注入
          data-family / data-theme 属性 ──► 启动页 CSS 变量族覆盖块生效 ──► HUD 换肤
```

**为什么走数据库而不是 localStorage**：启动页由 boot.py 自己的 HTTP 服务（:5850+ 端口段）吐出（boot.py:341-344），与前端 5800 **不同源，localStorage 互不可见**——数据库是唯一可靠通道。

**启动页换肤机制**（splash.html 条件极佳）：
- 全部颜色已走 CSS 变量（`--ion`/`--amber`/`--coral`/`--void` 等，splash.html:14-31 一处 `:root` 定义）→ 族换肤 = 加 `[data-family]/[data-theme]` 变量覆盖块，主结构零改动；
- boot.py 已有**只读 SQLite 读设置的现成先例**（`_read_launch_mode()` boot.py:429-456：`mode=ro` + timeout=2 + 异常兜底默认值）→ 新增 `_read_ui_theme()` 照抄该模式，boot 阶段后端未起也能读；
- 注入方式：吐 HTML 前 `replace('<html lang="zh-CN">', '<html lang="zh-CN" data-family=… data-theme=…>', 1)`（splash.html:2 锚点固定；`Cache-Control: no-store` 已有，无缓存问题）；**注入失败/读取失败 = 不加属性 = 现状默认观感，绝不阻塞启动**（启动页是 boot 关键 UX 路径）。

**六态换肤映射**：

| 用户所选主题 | 启动页观感 |
|---|---|
| Nebula · 深空（tech） | **现状青色 HUD，零变化**（现在这身本来就是深空味） |
| Sakura · 夜樱（sakura，默认） | 樱粉调 HUD（--ion→樱粉、底色微樱；**默认观感会变**，见决策点 D5） |
| Dali · 洱海月（dali） | 月金 × 湖青 HUD（月晕辉光、粒子转萤火金） |
| 三个亮色变体（light / tech-light / dali-light） | 对应族的**浅底版** HUD（雪白/雾白底、墨色文字、辉光减淡）——工作量约占启动页部分一半，见决策点 D5 |

**启动页 JS/canvas 的三处硬编码色**（CSS 变量管不到 canvas）：
- 粒子连线/流光 `rgba(94,234,255,…)`（splash.html:641、649、661-662）→ 提为读 `--ion-rgb` 变量（新增拆色变量）；
- 粒子点色板数组 → 按族选色板（青 / 樱粉 / 月金萤火）；
- Logo 渐变 `stop-color="#2EB6E8"`（:416）→ 渐变 stop 接 CSS 变量（`stop { stop-color: var(--logo-a) }`）。

### 3.2 影响面

- **现有两族零像素影响**：主界面新增选择器全部带 `[data-family='dali']` 前缀；启动页对 tech 深空零变化（映射表见 §1.4）。
- **编译期强制完整**：TopBar 两张 Record 穷举表不改就编译失败，不存在「改了类型漏了 UI」暗角。
- **持久化兼容**：localStorage 同键续用；回滚后残留 `'dali'` 值被 loadTheme 白名单拦下自动落回 sakura；启动页 `_read_ui_theme()` 同样白名单校验，脏值/旧库/无库全部落默认观感。
- **回写守卫（R5 防 clobber）**：setTheme 回写**只在 `settingsLoaded === true` 时执行**（未加载先静默 `loadSettings()` 补齐再发），且发送 `{…当前全量设置, theme: 新值}`——绝不发部分对象；后端整包替换语义（system.py:145-147）因此安全。回写失败静默（不打扰切主题动作），下次切主题或保存设置自然补齐。
- **启动页是 boot 关键 UX 路径**：boot.py 只加只读函数与字符串注入，全 try/except 兜底；最坏情形 = 注入不生效 = 现状观感，**绝不阻塞/拖慢启动**。
- **性能**：主界面动效全 transform/opacity，ui-lite 自动停；启动页粒子依旧仅在启动过场存在（`ui_performance=lite` 与启动页的联动现状本就不存在，不扩大范围，如实注记）。
- **并发会话**：与 knowledge/learning 域未提交改动零文件交集；launcher/ 目录当前无其他会话占用。
