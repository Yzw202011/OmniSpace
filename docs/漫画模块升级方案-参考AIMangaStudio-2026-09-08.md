## 一、AIMangaStudio 现状速览（2026-09-08 GitHub API 实查）

- **1,464 ⭐，2026-08 仍活跃**；技术栈 = React+Vite+TS 调 Google GenAI（Gemini）——**纯云端单路产品，无本地算力**。
- **仓库无 LICENSE 文件**（README 口称 MIT 但未落文件）→ **只学产品思路，一行代码不抄**（与 Long-Novel-GPT/DiffSensei 同铁律）。
- 产品流程概念（从组件命名提取）：故事输入 → AI 剧情建议 → 世界观设定 → 角色生成/角色上传 → 分格编辑（姿势编辑/蒙版重绘）→ 生成控制（抽卡对比）→ 漫画阅读视图 → 批量导出 PNG/PDF → 漫画变视频。

## 三、分批方案

### C1（薄改，建议先做）：漫画页双路感知 + 云端开关直达
- 漫画工作台头部加「出图引擎」状态胶囊：**本地显卡** / **云端 API（服务商名）**——数据源=轮询或生成响应的 `cloud` 字段 + `get slot 绑定状态`。
- 胶囊点击 → 弹「云端出图」小面板：显示 keyframe.image/asset.image 两工位当前绑定，提供「去设置绑定/解绑」直达（绑定/解绑 API 已有，设置页「云端 API 服务」卡片已有）。
- 生成按钮/浮层显示实际路由（「云端生成中…」vs「本地生成中…」）；四视图弹窗同理。
- 验收：真浏览器解绑态四格本地生成（cloud=false 透传 UI）+ 绑 mock 态走云端道（cloud=true 显示）+ 单测。

### C2（核心增量）：AI 写分格脚本（StoryInput → 分格网格一键填充）
- 新端点 `POST /manga/comic/script`：入参=故事梗概/一句话+期望格数(1~12)+画风 key；出参=分格数组（每格 description + 建议场景）。双路：优先 manga.text 云端槽绑定，回落本地对话引擎（与漫剧 AI 切分同构但输出更轻：只产画面描述不做镜头台）。
- 前端：工作台「AI 写分格」按钮 → 弹窗输入故事 → 覆盖/追加填充分格描述（可再逐格改）。
- 验收：本地路真弹（8B/4B 出 4 格描述落库）+ 云端路 mock + 提示词防复读沿用小说模块 detect_repetition 成果。

### C3：角色上传（手画/外部图作锚）
- 漫画页角色栏加「上传角色图」：新建资产（kind=character，prompt=用户描述）+ 传图走既有 `/comic/asset/{id}/image`。
- 诚实边界：单张上传图先作 ReferenceLatent 参考锚；**PuLID 人脸硬锁仍需四视图结构（closeup）**——UI 提示「可再生成四视图升级为人脸锁」。

### C4（=原 M2 对齐 AIMangaStudio 导出/阅读概念）
- 对话框/台词文字层（HTML 覆盖层，可编辑不进图）+ 整页导出 PNG 长图/PDF + 阅读视图（连续翻页预览）。

## 四、明确不做（本轮）
- 姿势编辑器、蒙版重绘（重交互工程，远期观察）；漫画变视频（复用漫剧 H3 链即可，不新做）。

## 五、拍板点
- **P1（C1 前置）**：keyframe.image/asset.image 工位是漫剧与漫画**共用**（现状，绑云端=漫剧关键帧也走云端）——A=接受共用（零改）；B=新增 `comic.image` 独立槽隔离两产品面（+1 工位注册，半天）。**荐 A 先行**（用户可随时解绑切换回本地，语义一致）。
- **P2（C2）**：AI 写分格的云端回落序：manga.text 槽 → 本地对话引擎（荐）；或独立 `comic.text` 槽。
- **P3**：C1~C4 一次排完还是「一个一个来」（荐一个一个来：C1→验收→C2）。
