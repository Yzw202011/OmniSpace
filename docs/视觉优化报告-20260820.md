## 二、全局性体系修改（跨页面）

### 2.1 CSS 分层架构（最终裁定链）

```
sakura.css 加载顺序：
  tokens.css → app.css → sakura-theme.css → polish.css → deep-polish.css
  → aurora-motion.css → signature.css → controls.css → interactions.css
  → premium.css → noir.css → refinement.css（最终裁定层）
```

`refinement.css` 作为最终层，承载 R1–R9 九组修复规则，本层声明覆盖所有前层。

### 2.2 控件尺寸双轨制收敛（R8 层，核心）

**问题**：老式 `.btn`/`.input` 类（123 处 / 36 处）与公用 `<Button>`/`<Input>` 组件并存，高度、内边距、图标档位各自为政。

**修复**（[refinement.css](file:///e:/OmniSpace/frontend/src/styles/refinement.css#L205-L289)）：

| 控件 | 统一规格 | 依据 |
|------|---------|------|
| 按钮 sm | 32px 高 / 13px 图标 | 4px 栅格 |
| 按钮 md | 36px 高 / 14px 图标 | 与表单控件同高 |
| 按钮 lg | 44px 高 / 16px 图标 | 页面 CTA 规格 |
| 输入框 | 36px 固定高 | 与按钮 md 同高，同行底对齐零差 |
| 卡片 | 16px padding / 嵌套卡 12px | 标准栅格层级 |
| 分段控件 | 28px | 项目铁律 |

**实测验证**（browser_evaluate 量测）：

```
「添加新主题」(主CTA)    height=36px  fontSize=13px  paddingLeft=16px
「让AI自己决定学什么」(次) height=32px  fontSize=12px  paddingLeft=8px
「+ 创建训练任务」(对照)   height=36px  fontSize=13px  paddingLeft=16px
```

主次按钮三重层级区分（尺寸 + 样式 + 字号），全站 `.btn-primary` 高度统一。

### 2.3 色彩令牌新增

| 令牌 | 暗色值 | 亮色值 | 用途 |
|------|--------|--------|------|
| `--color-slider-track` | `rgba(255,255,255,0.14)` | `rgba(26,26,46,0.14)` | 滑块未填充轨道 |

**解耦原因**：原滑块轨道复用 `--color-input-bg`（#0F3460），与卡片底色（#16213E）同为深蓝系，暗色下辨识度不足。专用令牌后轨道呈浅灰，填充（樱粉）与未填充（浅灰）对比鲜明。

### 2.4 文字对比度全局提升（R2 层）

- 暗色三级文字 `#6E7789`（对比度 ~3.5:1）→ `#9BA3B5`（≈5:1）
- 亮色三级文字同步调整为 `#6F7686`
- 一次性覆盖导航占位、ControlNet 说明、模型状态、更新时间等全部弱文案

### 2.5 交互反馈统一

- **禁用态**（R3）：主按钮禁用从"鲑鱼粉半透"改中性灰 `rgba(120,128,148,0.22)`，明确"不可用"而非"另一个强调色"
- **虚线拖拽区**（R4b）：边框提亮至 `rgba(155,163,181,0.5)` + 悬停粉染 + 微底色，"可拖放"暗示增强
- **滑块拖动**（R4a）：thumb 外圈 4px 半透粉环 + 12px 光晕
- **状态栏**（R5a）：相邻指示项加发丝分隔线，项内间距 6px

## 四、评分方法论

### 4.1 四维评分标准（十分制，从严评审）

| 维度 | 考察内容 | 9.5 分线 |
|------|---------|---------|
| 布局完整性 | 无错位、无溢出、无塌陷 | 仅存极细微可忽略问题 |
| 控件一致性 | 按钮 36px 栅格、输入框对齐、圆角统一 | 同类控件零高度差 |
| 视觉层级 | 标题/正文/辅助文字档位清晰、主次分明 | 三档文字一眼可分 |
| 整体精致度 | 间距节奏、图标统一、对比度、过渡动效 | 无"灰蒙蒙"或"突兀"区域 |

### 4.2 评审流程

1. 浏览器逐页导航（8 页全量），每页等待 2s 渲染稳定
2. 全屏截图 + DOM 快照留证
3. `browser_console_messages` 读取控制台（error 级一票否决对应维度）
4. `browser_evaluate` 量测关键控件 `getBoundingClientRect()` / `computedStyle`（防视觉误判）
5. 四维打分 + 扣分点必须引用具体元素与位置
