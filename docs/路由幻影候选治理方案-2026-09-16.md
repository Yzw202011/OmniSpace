## 根因链（已实证，行号为 09-16 现状）

1. 风格包 `base_prefs` klein 族常只有 9b（包定义早于 4b 接入）；
2. `gen_router.resolve_route` 白名单交集把 4b 滤掉（`gen_router.py:790-796`）；
3. 用户默认提权要求 `default ∈ prefs`（:797-800，注释自认盲区）——4b 不在偏好序时提权不生效；
4. 磁盘可用性兜底**返回不可用原序**而非白名单内就绪者（:812-815）；
5. 叠加 `_flux_model_dir_ready` 只认 `transformer/*.safetensors` 不认 `transformer-gguf/`（`paint_engine.py:309-329`）——9b 的 bf16 分片 09-10 已删（transformer/ 仅剩 33KB 索引骨架，真身 Q6_K 7.4G 在 gguf 子目录）→ 9b 自那天起=幻影候选。

## 方案（四段制）

**① 改动清单**
- `gen_router.py` 可用性兜底（:812-815）：`usable` 为空时改取「白名单 allowed ∩ 磁盘就绪」的第一个，其次才回落原序/9b 兜底；
- `paint_engine.PAINT_MODEL_CANDIDATES`：`flux2-klein-9b`（diffusers 项）除名——comfy fp8 单文件栈已接棒其质量位（`comfy_paint_available` 走 ComfyUI 权重，不受影响）；GGUF 恢复路线不做（`ready` 认 GGUF 的改法深度更大且 GGUF-diffusers 加载路径未验，放弃）；
- 候选表注释与 `_flux_model_dir_ready` 注释同步勘误（9b 项历史说明）。

**② 影响面**
- 所有走 `resolve_route` 的 diffusers 回落场景（关键帧回落/资产图/绘画）——无 comfy 或被闸回落时，链首位从幻影 9b 变为真实可载的 4b（在盘/白名单内/用户默认）；
- `flux2-klein-9b` 从 `available_models()` 与 manifest 消费方消失——模型管理页 diffusers 9b 条目隐去（comfy fp8 条目仍在，两套口径本就分列）；
- keyframe LoRA 救援点（9a9f1d8）保留——双保险；
- 不影响 comfy 主路径/四视图 legacy 4b/SDXL 兜底链。

**③ 验证方法**
- 单测：resolve_route 构造 prefs=[9b] + allowed=[9b,4b] + avail 只含 4b 的场景 → 断言链首位=4b（新增用例）；
- E2E：停 comfy（改 config gen_engine 临时 legacy 或权重改名）→ 生成一次关键帧 → 日志应见「路由底座 flux2-klein-4b 加载成功」而非 9b 失败三连；
- 回归：774+ 全量 pytest；风格包路由金标准快照不漂移。

**④ 风险与回退**
- 风险：风格包本意「9b 质量优先」在 diffusers 侧变成 4b——质量差半档（4b vs 9b），但现状是滑到 SDXL（差更多），净改善；
- 回退：两处改动各一行级，git revert 即回；候选表除名不动磁盘权重（39G 目录原地保留，回退即复现）。
