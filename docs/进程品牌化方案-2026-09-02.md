# 进程品牌化方案（2026-09-02）

> 时效状态：**现行**（实现已落地；起停链回归验证见 §5 诚实状态）
> 一句话：任务管理器里的全家进程从「一排蓝色 Python」变成「OmniSpace 一家人」——进程名规范化 + 项目 logo + 版本说明，零新依赖、带回退、可幂等重跑。

## 1. 背景与原理

Windows 任务管理器认进程只看三样：**exe 文件名**（进程名）、**exe 内嵌图标**、**exe 版本资源**（"说明"列）。本项目常驻进程原本全是 `python.exe/pythonw.exe` 换皮：

| 进程 | 改前身份 | 改后身份（任务管理器显示） |
| --- | --- | --- |
| 启动守护（boot.py，无窗链） | `pythonw.exe` | `OmniSpace-Boot.exe`「OmniSpace 启动守护进程」 |
| 后端（uvicorn，无窗链） | `pythonw.exe` | `OmniSpace-Backend.exe`「OmniSpace 后端服务」 |
| 启动守护（bat 控制台入口） | `python.exe` | `OmniSpace-BootC.exe`「OmniSpace 启动守护进程（控制台）」 |
| 后端（bat 控制台入口） | `python.exe` | `OmniSpace-BackendC.exe`「OmniSpace 后端服务（控制台）」 |
| 桌面窗口（pywebview，S1 桌面壳用） | — | `OmniSpace-Shell.exe`「OmniSpace 桌面窗口」 |
| 对话引擎（vLLM） | `py313\python.exe` | `OmniSpace-LLM.exe`「OmniSpace 对话引擎 (vLLM)」 |
| 绘画引擎（ComfyUI） | `python_embeded\python.exe` | `OmniSpace-Engine.exe`「OmniSpace 绘画引擎 (ComfyUI)」 |

技术地基（2026-09-02 三运行时实测）：
- 副本必须与原解释器**同目录**：嵌入式 Python 的 `._pth` 按 DLL 版本号定位（`python310.dll`/`python313.dll`），与 exe 文件名无关——py310 / py313 / python_embeded 三处改名副本均正确解析 sys.path（含 pydeps / site-packages）。
- 图标与版本信息经 `UpdateResourceW` 直接写入 PE 资源段（RT_GROUP_ICON/RT_ICON/RT_VERSION），**免编译、免 windres、纯 stdlib**；CPython 自带英文版本块（lang=0x0409）删除，统一为 0x0804/0x04B0 中文块。
- pywebview 6.2.1 的 `icon` 参数仅支持 GTK/QT——Windows 上窗口/任务栏图标来自 **exe 内嵌图标**，桌面壳跑在品牌 exe 里即自动挂 logo，无需改壳代码。

## 2. 工具与生成物

真源：`tools/brand_exe.py`（仓库存档；运行时目录不入 git）。七个副本落在各运行时目录内，`brand_exe.py --verify` 一键自校验（说明列+图标组读回比对）。版本号单一真源 = `src/config.yaml` 的 `app.version`。幂等：源 exe/图标/说明任一更新后重跑即刷新；运行中的副本被 Windows 锁写会自动跳过（`skip-running`），停机后重跑补齐。**C 后缀变体** = python.exe 底（控制台子系统），专供 bat 黑窗入口——保住后端日志的控制台回显，同时拿到品牌名。

## 4. 守卫同步（防「该杀杀不掉/误杀」）

- `launcher.py` `is_omnispace_process`：`is_python` 判据补 `'omnispace' in name`（品牌名不含 python 字样）。
- `vllm_service.py` `_reap_orphans`：见上表。
- `launcher/stop.py` **免改**：三处兜底匹配全按命令行关键字（`boot.py`/`src.main:app`+端口区间/`comfyui/main.py`），与 exe 名无关；品牌进程的 argv 仍含这些关键字，实测语义不变。
- 引擎可用性探测（h3_engine/comfy_paint_engine 的 `_COMFY_PY.is_file()`）免改：原版 python.exe 仍在（只加副本不删原版）。

## 6. 边界与不做清单
