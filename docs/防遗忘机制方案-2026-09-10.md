---

## 一、问题定性 + 实测证据

**根子不是 AI 记性差，而是横切要求没有强制入口**——自愈、日志这类「每个功能都要沾」的要求，全靠写代码那个会话「记得」，没有任何机制兜底。

已发生的遗忘（不是猜想）：

| # | 事件 | 证据 |
|---|------|------|
| 1 | 自愈漏装：漫剧「资产描述词/故事线描述词」两端点缺模型自动加载 | 2026-09-02 用户报「未就绪」后手工补网（ensure_loaded 补齐） |
| 2 | 日志漏打：大白话事件日志覆盖稀疏 | 实测（2026-09-10）：`log_event` 全仓 59 处调用、集中在 23 个文件；19 个后端 API 模块仅 3 个直接打点；新模块 novel / cloud **零打点** |
| 3 | 技术层有兜底、业务层没有 | `middleware/logger.py`（请求日志）与 `middleware/error_handler.py`（统一错误信封+suggestion）自动生效；漏的全是业务层横切：自动加载、降级标注、出路提示、log_event 大白话打点——这些必须每个功能手写，所以会漏 |

## 二、三层防线设计（A/B/C 可组合，推荐 A+B 先行）

### L-A 规矩层（软门，半小时见效，零风险）

CLAUDE.md 新增 **§16.7 横切关切检查单**（草稿见附录一，拍板后原样入库）+ §0 启动清单加一行。

效果：每个后续 AI 会话启动必读，方案四段制的「影响面」段必须回答横切五问。先例：§16 本身就是 2026-09-08 为治「AI 瞎写」立的，此路径已验证有效。
弱点：终究靠 AI 自觉，忘了还是忘——所以需要 B。

### L-B 闸门层（硬门，1-2 天）：横切审计第 5 闸

照 `scripts/dir_audit.py` 与 mypy 基线的成熟模式，新增 `tools/crosscut_audit.py` + 挂进 `.githooks` 提交闸（现有 ruff 三闸 + mypy 第 4 闸，加第 5 闸）。

**v1 审计规则（先上最痛、可静态判定的）**：

- **R1（首批，拦截级）**：`backend/api/` 下每个 API 模块文件（含 `manga/` 子包）必须至少含一处 `log_event` 调用；未达标的存量模块一次性登记进豁免清单（`tools/crosscut_exemptions.txt`，只增不减，像 mypy baseline）。
- **R2（首批，报告级）**：`backend/services/` 新增/修改文件中含长任务特征（`run_blocking` / 进度上报 / 生成类动词）而无 `log_event` 的，审计报告提示但不拦截（语义静态判定误报高，先观察）。
- **R3（二批，待研究）**：涉及模型推理的端点须走 `ensure_loaded` 模式——静态判定难（间接调用多），v1 不上，靠 §16.7 规矩 + 验收实弹把关。

**语义限制（诚实声明）**：闸门只能查「有没有写这行」，查不出「写得对不对、够不够」——质量仍靠 L-A 规矩 + §16.2 实弹验收。

### L-C 架构层（根修，并入自愈方案一起拍板）

方向：横切能力「默认自带」——如统一装饰器/依赖，路由声明时自动获得模型自动加载 + log_event 打点 + 错误出路，新功能想漏都难。
成本最高（动基础设施 + 全量回归），**不在本方案首批动工**，与 2026-09-08 自愈评估（荐 L1 一键体检 + L2 人话化，同样待拍板）合流拍板。

## 附录一：CLAUDE.md §16.7 草稿（拍板后原样入库）

```markdown
### 16.7 横切关切检查单（2026-09-10 用户提出「AI 会遗忘自愈/日志联动」）

任何新增功能或功能修改，方案书「影响面」段必须回答以下五问，交付验收逐条核对：

1. **失败出路**：失败时用户看到什么？必须带 suggestion 出路提示，禁止裸报错。
2. **自动加载**：涉及模型的功能，未加载时必须自动加载 + 进度可见（ensure_loaded
   模式），不许让用户「再点一次」。
3. **降级诚实**：存在降级路径的，结果必须标 degraded:true + degrade_reason。
4. **日志联动**：用户可感知的动作（生成/加载/导出/失败）必须在所在模块 log_event
   打点（至少成/败两态，friendly 用大白话，>3s 记 duration_ms）；新增 API 模块
   必须过横切审计闸（tools/crosscut_audit.py，提交闸第 5 闸）。
5. **资源礼貌**：重量级操作接显存让渡/释放；互斥功能走排队，不秒拒。
```
