# 风格包草案(2026-09-02,方案 A:先走自定义包通道试效果)

四个 JSON 已过后端 `parse_custom_pack` 真实校验,直接在漫剧页导入即可,**不用改代码**。

## 导入步骤

1. 打开漫剧页 → 风格库 → 新建自定义风格;
2. 点「导入风格包(JSON)」选下面任一文件(名称会自动回填);
3. 保存 → 建项目选用该风格 → 分镜生图看效果;
4. 验证路由:后端日志 grep `custom:`,应看到对应 sid。
