【项目简介】
这是 OmniSpace AI 项目的纯前端静态演示版本，无需后端服务即可完整体验所有页面和交互功能。
所有 API 请求均由本地 mock 层拦截并返回模拟数据。

【快速启动】
方法一（推荐）：双击 "启动演示版.bat"，自动启动服务器并打开浏览器
方法二：手动启动
  1. 打开命令行，进入本目录
  2. 执行: python -m http.server 8899
  3. 浏览器访问: http://localhost:8899/

注意：不能直接双击 index.html 打开（file:// 协议下 Babel 无法加载外部 JSX 文件）

【包含页面】

一级页面（7个）：
  1. 首页 - 作品区、今日灵感、系统状态、快捷入口
  2. 漫剧创作 - 项目选择与新建
  3. AI对话 - 多轮对话、SSE流式回复
  4. AI绘画 - 5种生成模式
  5. 知识学习 - 学习系统、训练面板、质量评估
  6. 模型管理 - 模型注册表、显存池、下载、LoRA训练
  7. 设置 - 系统设置6个标签页

二级页面：
  漫剧创作：
    - 项目选择页
    - 剧本导入页
    - 分镜工作台（11列分镜表）
  AI绘画：
    - 文生图、图生图、多图生成、首尾帧、图生视频
  知识学习：
    - 学习入口、训练面板、质量评估
  设置：
    - 系统概览、任务队列、激活与更新、诊断与维护、沙盒与插件、偏好画像

三级页面（漫剧工作台右侧抽屉）：
  1. 音色配置 - 角色音色绑定、情绪标签管理、音色克隆
  2. 3D导演台 - 机位/灯光/运动参数、全屏Three.js导演台
  3. 四工序流水线 - 文生图→图生视频→配音→合成
  4. 空间推理 - 快速/专家双模式、7步管线输出

【技术说明】
- 前端框架: React 18 + Babel Standalone（浏览器端实时编译JSX）
- 样式: Tailwind CSS + 自定义设计令牌
- 图标: Lucide Icons
- 3D引擎: Three.js
- 图谱: Cytoscape.js
- Mock层: 拦截全局 fetch 和 WebSocket，返回模拟数据

【演示模式限制】
1. 所有数据均为模拟数据，刷新后重置
2. AI对话/绘画生成的内容为固定模拟回复
3. 文件上传功能仅作演示，不会实际处理文件
4. 3D导演台需要加载 Three.js，首次打开可能较慢
5. 部分高级功能（如实际模型训练、视频生成）仅展示UI

【常见问题】
Q: 页面空白怎么办？
A: 确保通过 HTTP 服务器访问，不要直接用 file:// 打开 index.html

Q: 端口 8899 被占用怎么办？
A: 可以修改启动脚本中的端口号，或手动指定其他端口: python -m http.server 8080

Q: 首次加载很慢？
A: Babel 需要在浏览器端实时编译 JSX 文件，首次加载约需 5-10 秒，属正常现象

Q: 如何停止服务？
A: 关闭启动时弹出的最小化命令行窗口即可
