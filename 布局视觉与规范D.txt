第一章 整体布局架构
================================================================================

1.1 五层布局架构

OmniSpace AI v2.3.1 采用经典的五层布局架构，各层级严格遵循以下物理尺寸与功能定义。
整体使用 Flexbox 布局，根容器为 100vw x 100vh，overflow: hidden 防止滚动条。

布局示意：

+------------------------------------------------------------------------------+
|  顶部导航栏 (TopNav)  高度: 48px  z-index: 1000                    - □ ×    |
+------------------------------------------------------------------------------+
| 左侧导航  |  主内容区 (MainContent)                    |  右侧面板          |
| 64px/     |                                            |  320px             |
| 260px     |  flex: 1, overflow-y: auto                |  可折叠            |
|           |                                            |                    |
| [对话]    |  ← 根据路由动态渲染对应页面组件             |  ← 按模块切换      |
| [绘画]    |                                            |                    |
| [漫剧]    |                                            |                    |
| [学习]    |                                            |                    |
| [模型]    |                                            |                    |
| [风格]    |                                            |                    |
| [设置]    |                                            |                    |
| [帮助]    |                                            |                    |
| ←Toggle→  |                                            |                    |
+------------------------------------------------------------------------------+
| 底部状态栏 (StatusBar)  高度: 28px  CPU | GPU | VRAM | RAM | 学习状态        |
+------------------------------------------------------------------------------+

各层级定义：

层级    组件名              高度/宽度                    z-index   功能定义
第1层   TopNav 顶部导航栏   固定 48px (h-12)             1000      Logo、全局搜索、通知中心、用户菜单、主题切换
第2层   Sidebar 左侧导航栏  展开 260px / 折叠 64px        900       模块导航树、空间切换器、收藏标记、折叠按钮
第3层   MainContent 主内容区 flex: 1 自适应               1         多标签页容器，根据路由渲染对应页面组件
第4层   RightPanel 右侧面板 展开 320px / 折叠 0px         800       上下文属性面板、操作历史、AI对话侧边栏
第5层   StatusBar 底部状态栏 固定 28px (h-7)              700       系统运行状态、API连接、版本号、资源占用


1.2 响应式断点设计

断点名称     宽度范围          布局策略         侧边栏               右侧面板                      状态栏
Desktop     ≥1440px          完整五层布局     默认展开 260px       默认展开 320px                显示全部指标
Laptop      1280px-1439px    右侧面板折叠     默认展开 260px       折叠为 64px 图标抽屉          显示核心指标
Tablet      768px-1279px     精简三栏         默认折叠 64px        完全隐藏（浮动按钮唤出）      显示精简指标
Mobile      <768px           单栏布局         全屏覆盖层 (Overlay) 完全隐藏                      隐藏，由底部导航替代

1.3.3 亮色主题覆盖

通过 [data-theme="light"] 属性选择器覆盖深色主题变量。
亮色主题下主要变更：
- 背景变为 #FFFFFF / #F8F9FC / #F0F2F7
- 文字变为 #1A1A2E / #5A6070 / #8A90A0
- 边框变为 #E2E5ED / #C8CDD8
- 阴影减弱为 0 1px 2px rgba(0,0,0,0.05) 等轻量阴影
- 主色 #FF6B9D 保持不变
切换时使用 transition: all 500ms ease 实现平滑过渡，切换无闪烁。

================================================================================
第二章 顶部导航栏（TopNav）
================================================================================

顶部导航栏固定高度 48px，z-index: 1000，贯穿整个窗口宽度。
背景色 --color-bg-primary，底部 1px 边框 --color-border。
从左到右依次排列以下组件：

| [Logo]  |  [全局搜索 Ctrl+K]  |  [窗口标题]  ......  |  [通知🔔] [用户👤] [主题🌗] |
  48px宽     flex-1居中             自适应                各32px宽


2.1 Logo 区域（LogoArea）

位置：顶部导航栏最左侧，宽度 48px，高度 48px，居中放置。
功能：显示 OmniSpace AI 品牌图标（自定义 SVG，樱花粉色描边），点击后回到 Dashboard 或上次激活的模块首页。
样式：图标尺寸 28x28px，hover 时旋转 5deg + 亮度提升 10%，transition 200ms。
组件类型：布局组件。


2.2 全局搜索触发器（GlobalSearch）

位置：Logo 右侧，宽度 flex-1（自适应扩展），高度 32px，垂直居中于顶栏。
功能：
  - 默认显示半透明搜索框，占位文字"搜索功能、页面、设置、文档... (Ctrl+K)"
  - 点击或按 Ctrl+K 唤起全屏搜索覆盖层（半透明遮罩 rgba(0,0,0,0.6)）
  - 搜索框在屏幕中央弹出，宽度 600px，带 300ms 缩放+淡入动画
  - 输入 <200ms 显示结果，结果分4类：功能 / 页面 / 设置 / 文档
  - 每类最多显示5条，支持键盘上下键导航，Enter跳转，Esc关闭
  - 结果项 hover 背景变为 --color-primary-light
  - 搜索结果项格式：左侧 16px 图标 + 标题 + 右侧分类标签
样式：搜索框背景 --color-bg-input，圆角 20px（胶囊形），左侧搜索图标 16px，文字大小 13px。
组件类型：交互组件。
快捷键：Ctrl+K


2.3 窗口标题（WindowTitle）

位置：全局搜索右侧，宽度自适应，高度 48px，文字垂直居中。
功能：显示当前激活的模块名称和页面标题，格式为"OmniSpace AI v2.3.1 - {当前模块名}"。
样式：字号 14px，颜色 --color-text-secondary，font-weight: 500。
组件类型：展示组件。


2.4 通知中心（NotificationCenter）

位置：顶栏右侧第一个图标，宽度 32px，高度 32px。
功能：
  - 铃铛图标（Lucide Bell），24x24px，颜色 --color-text-secondary
  - 有新通知时：图标右上角红色圆点徽章（8px直径，背景 --color-error），带脉冲动画
  - 点击展开下拉面板（宽度 360px，最大高度 400px，从顶部向下展开 250ms ease）
  - 通知类型：
    * 任务完成：绿色左条（3px solid --color-success）
    * 错误告警：红色左条（3px solid --color-error）
    * 训练完成：黄色左条（3px solid --color-accent-warm）
    * 系统通知：蓝色左条（3px solid --color-info）
  - 每条通知结构：标题（13px粗体）+ 摘要（12px）+ 时间戳（11px灰色），高度约 72px
  - hover 时背景变为 --color-bg-card，右侧显示"标记已读"和"删除"按钮
  - 底部"全部已读"按钮和"查看全部"链接
  - 无通知时显示空状态图标 + "暂无通知"
样式：下拉面板背景 --color-bg-secondary，圆角 8px，阴影 --shadow-lg。
组件类型：交互组件。


2.5 用户头像下拉菜单（UserMenu）

位置：顶栏右侧第二个，通知中心左边，宽度 32px。
功能：
  - 圆形头像（32x32px），默认显示用户名首字母，背景 --color-primary，文字白色
  - 点击展开下拉菜单（宽度 200px，从下方展开 200ms ease）
  - 菜单项（每项高度 36px，hover 背景 --color-bg-card，左侧 16px 图标）：
    * 用户名（只读显示，字号 14px 粗体）
    * 个人设置（User 图标）
    * 快捷键设置（Keyboard 图标）
    * 关于（Info 图标）
    * —— 分隔线 ——
    * 退出登录（LogOut 图标，文字颜色 --color-error）
样式：下拉菜单背景 --color-bg-secondary，圆角 8px，阴影 --shadow-md。
组件类型：交互组件。


2.6 主题切换按钮（ThemeToggle）

位置：顶栏最右侧，宽度 32px，高度 32px。
功能：
  - 图标切换：深色模式显示月亮图标（Moon），亮色模式显示太阳图标（Sun）
  - 点击切换 data-theme 属性，全部页面/组件/弹窗同步切换，过渡 500ms
  - 切换时无闪烁：先在 body 添加 theme-transitioning 类禁用过渡，DOM 更新后移除
样式：图标 20px，颜色 --color-text-secondary，hover 变为 --color-accent-warm。
组件类型：交互组件。
快捷键：Ctrl+Shift+T


================================================================================
第三章 左侧导航栏（Sidebar）
================================================================================

左侧导航栏位于窗口左侧，高度填满顶栏与状态栏之间的空间。
支持展开（260px）与折叠（64px）两种状态，通过底部的 Toggle 按钮切换。
背景色 --color-bg-secondary，右侧 1px 边框 --color-border。


3.1 空间切换器（SpaceSwitcher）

位置：导航项列表上方，展开状态时高度 56px，折叠状态时隐藏。
功能：显示当前工作空间名称（如"默认空间"、"创作空间"），点击展开下拉列表切换空间。
每个空间独立保存导航状态、布局配置和未保存项目。
样式：展开时显示空间名称 + 下拉箭头，字号 14px，颜色 --color-text-primary。
组件类型：交互组件。


3.2 导航项列表（NavList）

位置：空间切换器下方，占据侧边栏主要空间，垂直排列。
导航项详细列表：

序号  图标              名称      路由            功能说明                           互斥规则
1     MessageCircle     AI对话    /chat           OmniChat 多模态对话界面            与绘画/漫剧视频/训练互斥
2     Palette           AI绘画    /paint          OmniDraw 文生图/图生图/局部重绘    与对话/漫剧视频/训练互斥
3     Film              漫剧创作  /storyboard     OmniComic 6阶段工作流              视频生成阶段与其他AI模块互斥
4     BookOpen          知识学习  /learning       OmniLearn 自主学习与知识库         后台运行不互斥
5     Package           模型管理  /models         ModelManager 模型库管理            不互斥（仅管理操作）
6     Video             视频风格  /style          VideoStyle LoRA训练与风格应用       训练时与其他AI模块互斥
7     Settings          设置      /settings       系统设置（通用/硬件/网络/训练/隐私） 不互斥
8     HelpCircle        帮助      /help           离线帮助文档、快捷键参考            不互斥


3.3 导航项样式与交互（NavItem）

展开状态（260px）：
  - 每项高度 44px，宽度 100%，左内边距 20px，图标 24px + 间距 12px + 文字 14px
  - 默认态：文字颜色 --color-text-secondary，图标同色
  - 当前激活项：左侧 3px 粉色条（--color-primary）+ 背景 --color-primary-light，文字/图标变为 --color-primary
  - Hover 态：背景 --color-bg-card，文字颜色提升为 --color-text-primary
  - 置灰态（功能互斥时）：opacity: 0.4，cursor: not-allowed，hover 显示 Tooltip "当前GPU资源不足，请等待任务完成"
  - 资源恢复后：自动从置灰态恢复为可用态，200ms 过渡动画
  - 切换后输入框内容、对话历史、参数设置均保持
  - 1秒内连续切换5个模块各3次，无白屏/闪烁/卡顿

折叠状态（64px）：
  - 仅显示图标，24x24px 居中，每项宽度 64px
  - Hover 时显示 Tooltip（右侧弹出，白底深字，200ms 淡入），显示功能名称
  - 激活态：左侧 3px 粉色条 + 图标背景 --color-primary-light

切换动画：展开/折叠时宽度过渡 300ms ease-in-out，文字淡入/淡出 200ms。页面切换时间 <200ms。
组件类型：交互组件。


3.4 收藏标记（Favorites）

位置：导航项列表底部，ToggleBtn 上方。展开状态时显示，折叠状态时隐藏。
功能：显示用户收藏的常用页面/项目快捷入口，最多显示 5 个。
每项显示星形图标（14px）+ 名称（13px），点击直接跳转。
样式：高度 36px，hover 背景 --color-bg-card。
组件类型：展示组件。


3.5 底部折叠按钮（ToggleBtn）

位置：侧边栏最底部，高度 40px，宽度 100%。
功能：ChevronLeft/ChevronRight 图标切换，点击切换侧边栏展开/折叠状态。
展开时图标指向左，折叠时指向右。Hover 背景变为 --color-bg-card。
样式：顶部 1px 边框 --color-border，图标 20px，颜色 --color-text-secondary。
组件类型：交互组件。


================================================================================
第四章 主内容区（MainContent）
================================================================================

主内容区占据侧边栏与右侧面板之间的全部空间（flex: 1），是应用核心交互区域。
背景色 --color-bg-primary，内边距 24px，overflow-y: auto。
支持多标签页（Multi-Tab）布局。

4.1 多标签页容器（MultiTabContainer）

位置：主内容区顶部，高度 36px，宽度 100%。
功能：
  - 每个 Tab 对应一个独立路由或视图组件，同时可打开多个模块
  - Tab 标签：高度 32px，最大宽度 180px，文字超出省略号，左侧显示模块图标 14px
  - 当前激活 Tab：底部 2px 粉色指示条，文字颜色 --color-text-primary
  - 非激活 Tab：文字颜色 --color-text-secondary，hover 时背景变亮
  - 每个 Tab 右侧有关闭按钮（X 图标 12px），hover 变红
  - Tab 过多时左右滚动箭头出现
  - 右键菜单：关闭当前/关闭其他/关闭全部/在新标签打开
样式：背景 --color-bg-secondary，底部 1px 边框 --color-border。
组件类型：布局组件。

4.2 路由视图（RouterView）

位置：多标签页容器下方，占据剩余全部高度，overflow-y: auto。
功能：使用 React Router 7 的 <router-view> 渲染当前激活路由对应的页面组件。
页面切换时使用 fade-in + slide-up 动画，时长 300ms ease-out。内边距 24px。
组件类型：布局组件。


================================================================================
第五章 右侧面板（RightPanel）
================================================================================

右侧面板宽度默认 320px（可拖拽调整 280~500px），根据当前激活的模块动态渲染对应的面板组件。
支持展开/折叠，折叠时完全隐藏（宽度 0px），通过顶栏浮动按钮重新唤出。
背景色 --color-bg-secondary，左侧 1px 边框 --color-border。

5.1 各模块右侧面板内容

当前模块    面板组件       面板内容

- 展开/折叠：面板从右侧滑入（300ms ease），折叠时宽度过渡至 0px，内容淡出

    * 流式打字机效果：AI回复逐字显示，首token延迟 <500ms（标准上下文）/ <800ms（8K满上下文）
    * 停止生成按钮：生成中显示，点击后已生成部分保留，显示"(已停止)"标记

  - 虚拟列表：使用 @tanstack/react-virtual，10k条消息滚动 FPS>55
  - 空状态：居中显示欢迎图标 + "开始新对话" + 快捷操作建议

组件类型：展示+交互组件。

    * 拖拽上传：拖入时输入框高亮显示虚线边框

9.3.5 中央3D视口（Viewport3D）

位置：资产库右侧，flex: 1。
功能：
  - Three.js r170 WebGL 浏览器内渲染，无独立进程
  - 地面网格（10x10 灰色网格线）
  - 环境光 + 方向光
  - 透视相机 FOV 60°
  - 帧率 >= 60fps（帧率<15fps时自动降低渲染质量，右上角黄色三角形警告）

  相机控制：
  - 左键拖拽旋转（水平360°无限制，垂直-80°~80°）
  - 右键拖拽平移
  - 滚轮缩放（0.5~50米）
  - 双击3D对象：相机平滑动画过渡（500ms）聚焦
  - F键：重置相机

  对象选中与操作：
  - 点击对象选中：蓝色轮廓线（2px #4A90D9）+ Gizmo变换手柄
  - 点击空白或 Esc：取消选中
  - Delete键：删除对象（弹出确认）
  - Ctrl+Z：撤销

  Transform Gizmo：
  - 平移(W)：拖拽红/绿/蓝箭头（X/Y/Z轴），中心白色方块（平面移动），Shift+拖拽精度0.001m
  - 旋转(E)：拖拽红/绿/蓝圆圈，旋转时显示角度数值，Shift+拖拽15°步进，Ctrl+拖拽精度0.1°
  - 缩放(T)：拖拽红/绿/蓝方块，中心白色方块（等比缩放），范围0.01~100

  网格吸附：
  - 开启后移动时位置自动吸附到网格交点
  - 蓝色虚线标记
  - 切换间距：0.1m / 0.25m / 0.5m / 1m / 2m

  表面吸附：
  - 道具底部自动贴合桌子表面
  - 蓝色轮廓（200ms）

  多选：
  - Ctrl+点击追加选中

14.4 动画系统

14.4.1 过渡时长

--transition-fast: 150ms ease-in-out     // 按钮hover、图标变化
--transition-normal: 250ms ease-in-out   // 面板展开/折叠、下拉菜单
--transition-slow: 400ms ease-in-out     // 路由切换、大面板过渡

14.4.2 关键动画

- 淡入淡出（fadeIn/fadeOut）：opacity 0→1，250ms
- 缩放淡入（scaleIn）：scale(0.9)→1 + opacity 0→1，250ms（弹窗）
- 从上滑入（slideInDown）：translateY(-20px)→0 + opacity 0→1，300ms（通知）
- 从右滑入（slideInRight）：translateX(20px)→0 + opacity 0→1，300ms（Toast）
- 从下滑入（slideInUp）：translateY(20px)→0 + opacity 0→1，300ms（路由切换）
- 旋转（spin）：rotate(0deg)→360deg，1s linear infinite（Loading 图标）
- 脉冲（pulse）：scale(1)→1.05→1，2s ease-in-out infinite（通知红点）
- 抖动（shake）：translateX(0)→-10px→10px→-10px→0，400ms（错误提示）

14.4.3 动画工具类

.fade-enter-active, .fade-leave-active { transition: opacity 0.25s ease }
.fade-enter-from, .fade-leave-to { opacity: 0 }
.slide-up-enter-active { transition: all 0.3s ease-out }
.slide-up-enter-from { opacity: 0; transform: translateY(20px) }

  - Error：背景 rgba(224,85,85,0.15)，文字 --color-error

16.4 弹窗动画规范

- 模态弹窗：缩放 0.9→1 + 淡入，250ms ease-out；关闭时反向 200ms
- 抽屉：从侧边滑入，300ms ease-out；关闭时滑出 250ms
- Toast：从右侧滑入 + 淡入，300ms；消失时淡出 + 右移 200ms
- 通知：从顶部滑入 + 淡入，300ms；消失时淡出 200ms
- 灯箱：背景变黑 + 图片放大，300ms；关闭时反向 250ms

16.5 确认弹窗规范

危险操作（删除/清空/覆盖）必须使用确认弹窗：
- 标题：操作描述（如"确定删除此项目？"）
- 内容：影响说明（如"删除后无法恢复，关联的所有资产和分镜将一并删除"）
- 按钮：取消（灰色）| 确认（红色）
- 高危操作：要求输入确认文本（如输入"DELETE"或项目名称）
- 确认按钮在输入正确文本前禁用

16.6 生成记录系统弹窗

位置：各模块顶部的"生成记录"按钮。
弹窗尺寸：宽度 800px，最大高度 600px。
内容：
  - 6个Tab标签横向排列可滚动：
    * 角色图 | 场景图 | 道具图 | 分镜图 | 导演台截图 | 视频
  - 每个Tab下显示对应类型的生成记录网格：
    * 缩略图网格（每行4~6个，120x120px）
    * 每项：缩略图 + 时间戳 + 来源模块标签
    * hover显示操作按钮：预览/下载/删除
    * 支持多选批量删除
  - 记录永久保留，不自动清理
  - 支持按日期范围筛选
  - 支持按项目筛选
  - 支持搜索

19.1.1 基础配置

- 基础URL：http://localhost:8000/api/v1

- 超时设置：30秒（默认）/ 300秒（生成类请求）

19.1.2 统一响应格式

interface ApiResponse<T> {
  success: boolean;
  data: T | null;
  error: {
    code: string;
    message: string;
    detail: string;
    suggestion?: string;
  } | null;
  meta: {
    request_id: string;
    timestamp: string;
    duration_ms: number;
  };
}

19.1.4 错误处理

- 网络错误：Toast提示"网络连接失败，请检查网络设置"
- 超时错误：Toast提示"请求超时，请重试"
- 404错误：Toast提示"资源不存在"
- 500错误：Toast提示"服务器内部错误"+ 错误详情
- 模型未加载错误（MODEL_NOT_LOADED）：弹窗提示并跳转模型管理页
- 显存不足错误（VRAM_INSUFFICIENT）：弹窗提示并显示显存管理面板
- 统一错误码体系：1xxx模型 / 2xxx知识 / 3xxx浏览器 / 4xxx训练 / 5xxx系统 / 6xxx前端

19.2 WebSocket 实时通信

19.2.1 连接配置

- URL：ws://localhost:8000/ws
- 协议：WebSocket
- 心跳间隔：30秒
- 重连策略：指数退避（1s/2s/4s/8s/16s/32s），最大重连次数10次
- 消息格式：JSON

19.2.2 消息类型

19.2.3 前端处理

- useWebSocketStore 统一管理连接状态
- 按消息类型分发到对应 store
- 连接断开时：
  * 状态栏显示"与后端服务断开连接，正在重连..."
  * 指数退避重连
  * 重连成功后恢复所有订阅
  * 重连失败10次后显示"连接失败，请检查后端服务是否运行"

19.3 文件上传通信

- 上传方式：FormData + Axios POST
- 分片上传：大文件（>50MB）使用分片上传，每片 5MB
- 上传进度：onUploadProgress 回调更新进度条
- 支持格式：图片（JPG/PNG/WebP/GIF）/ 视频（MP4/MOV/WebM）/ 音频（WAV/MP3）/ 文档（PDF/TXT/DSL）
- 文件大小限制：图片 10MB / 视频 500MB / 音频 50MB / 文档 50MB
- 超出限制：前端拦截 + Toast提示"文件大小超出限制（最大XX MB）"

19.4 本地存储通信

- ChromaDB：向量数据（知识库嵌入向量）

20.1 React 19.2 组件规范

20.1.1 组件命名

- 组件名使用 PascalCase：OmniButton.vue
- 组件文件名与组件名一致
- 全局注册组件以 Omni 前缀命名
- 页面级组件以 Page 后缀命名：ChatPage.vue

20.1.2 组件结构（Function Component + Hooks + Function Component）

标准组件结构：
  <template>
    <!-- HTML模板 -->
  </template>

  <Function Component lang="ts">
  // 1. 导入
  import { ref, computed, onMounted } from 'vue'
  import { useAppStore } from '@/stores/useAppStore'

  // 2. Props & Emits
  interface Props {
    modelValue: string
    label?: string
    disabled?: boolean
  }
  const props = ES6 default params(Props interface<Props>(), {
    label: '',
    disabled: false
  })
  const emit = Props callback<{
    'update:modelValue': [value: string]
    change: [value: string]
  }>()

  // 3. 响应式状态
  const inputValue = ref(props.modelValue)

  // 4. 计算属性
  const displayLabel = computed(() => props.label || '默认标签')

  // 5. 方法
  const handleChange = (e: Event) => {
    const value = (e.target as HTMLInputElement).value
    inputValue.value = value
    emit('update:modelValue', value)
    emit('change', value)
  }

  // 6. 生命周期
  onMounted(() => {
    // 初始化逻辑
  })
  </script>

  <style CSS Modules>
  /* 组件样式，使用 CSS 变量 */
  </style>

20.1.3 Props 规范

- 使用 TypeScript interface 定义 Props
- 必填 Props 不加 ?，可选 Props 加 ?
- 使用 ES6 default params 提供默认值
- 避免 any 类型，使用具体类型

20.1.4 事件规范

- 使用 Props callback 泛型定义事件
- 事件名使用 kebab-case
- value + onChange 使用 update:modelValue 标准事件

20.2 TypeScript 规范

- 严格模式：strict: true
- 禁止 any 类型（eslint 报错），必须使用 unknown 或具体类型
- 接口命名使用 PascalCase，不加 I 前缀
- 枚举命名使用 PascalCase
- 类型别名使用 PascalCase
- 函数返回类型必须显式标注

20.3 CSS 规范

- 优先使用 Tailwind CSS 工具类
- 复杂样式使用 <style CSS Modules> + CSS 变量
- 禁止硬编码颜色值，必须使用 var(--color-*) 变量
- 禁止 !important（特殊情况除外，需注释说明）
- 类名使用 kebab-case
- Scoped 样式使用 :deep() 穿透子组件

20.4 文件命名规范

- 组件文件：PascalCase（OmniButton.vue）
- 页面文件：PascalCase + Page 后缀（ChatPage.vue）
- 工具文件：camelCase（format.ts）
- 类型文件：camelCase（api.ts）
- 样式文件：kebab-case（variables.css）
- 常量文件：camelCase（constants.ts）

20.5 代码格式化

- 使用 ESLint + Prettier
- 缩进：2 空格
- 引号：单引号
- 分号：结尾加分号
- 最大行宽：120 字符
- 尾逗号：es5（数组和对象最后一项加逗号）

20.6 Git 提交规范

格式：type(scope): description

类型：
  - feat: 新功能
  - fix: 修复Bug
  - refactor: 重构
  - style: 样式调整（不影响功能）
  - docs: 文档更新
  - test: 测试相关
  - chore: 构建/工具/依赖更新
  - perf: 性能优化

示例：
  feat(chat): 添加流式打字机效果
  fix(director): 修复3D视口内存泄漏
  refactor(models): 重构模型加载逻辑
