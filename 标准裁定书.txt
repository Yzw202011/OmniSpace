本文档是对 OmniSpace AI v2.3.1 项目五份技术文档（修正版A/B/E、修改版C、测试计划）

第一章 文档体系定位
================================================================================

本项目共有五份核心技术文档，经统一裁定后，各文档的定位与层级关系如下。
任何文档间的内容冲突，均按此层级关系裁决。

1.1 文档层级关系

修正版E — 唯一权威全量技术文档 [权威源]
  含全部12章，涵盖架构设计、模块规格、API定义、硬件适配、资源配置、安全策略等
  完整技术细节。所有技术决策以E为准。

修正版A — 开发计划子集 [E的子集]
  侧重任务清单（P0/P1/P2分级）和工时估算。技术内容引用E，不独立定义技术规格。
  任务编号格式须与E保持一致。

修正版B — 中文精简版 [E的精简版]
  E的中文摘要版本，面向非技术读者和管理层。需补齐缺失章节（E中有但B中缺失的
  内容），不得包含与E冲突的规格。

修改版C — 编程语言规范附录 [独立附录]
  独立文档，定义8种编程语言的职责边界、编码铁律和跨语言协作规范。被E引用但
  不从属于E。前端框架须更新为Vue3。

测试计划 — 可执行验证文档 [独立验证]
  独立的可执行测试用例集合，以附录逐条统计的414条为准。与E形成验证闭环，
  但不从属于任何技术文档。


1.2 引用规则

引用方       被引用方     引用规则
修正版A      修正版E      技术规格、硬件配置表、模型清单、API路由等必须引用E，
                          A仅保留任务清单和工时信息
修正版B      修正版E      章节结构与E对齐，缺失章节须按E补齐，内容为E的中文摘要，
                          不得自行定义新规格
修正版E      修改版C      E在编程语言相关章节引用C的规范条目，不重复定义编码标准
测试计划     修正版E      测试用例的验收标准须与E的38项核心要求清单保持一致，
                          测试编号采用统一TASK格式


1.3 文档维护责任

修正版E — 架构组维护
  任何技术变更须先更新E，再同步至A/B。E是唯一可以定义新规格的文档。

修正版A — 项目管理组维护
  任务拆分和工时调整可直接更新A，但技术内容变更须先经E确认。

修改版C — 后端架构组维护
  编程语言规范变更独立于E发布，E通过版本号引用C的特定版本。

测试计划 — QA组维护
  测试用例增删独立于技术文档，但验收标准须与E的38项要求同步。

4.1 首字延迟修正

【差异发现】
各文档对 TASK-CHAT-001（Qwen3-VL 多模态对话）的首字延迟(TTFT)验收标准存在冲突：
  - 修正版E(1.5) & 修正版A(1.5)：首字延迟 <800ms
  - 修正版B：首 token <500ms
  - 修正版E(性能测试章节)：TTFT P95 <200ms（目标值与验收标准混用）

裁定结果：统一修正为分场景双指标：

场景                      验收标准                  说明
标准上下文（≤4K tokens）  首字延迟 <500ms           日常对话、Agent工具调用等常规场景
8K满上下文                首字延迟 <800ms           长剧本润色、大段分镜描述生成等满上下文场景

修正位置：
  - 修正版E 第1.5节 第1项：验收标准列修改为"首字延迟 <500ms（标准上下文）/ <800ms
    （8K满上下文），显存 <12GB"
  - 修正版A 第1.5节 TASK-CHAT-001 行：同步修改
  - 修正版B 对应章节：同步修改
  - 测试计划 TASK-CHAT-001 相关用例：预期结果同步修改为双指标

【注意】
E性能测试章节中"TTFT P95 <200ms"为内部优化目标值，不是验收标准。
验收标准以1.5节的414条测试用例预期结果为准。两者不冲突：优化目标更激进，
验收标准为底线。

9.1 分镜图重绘策略

【差异发现】
修正版E中OmniDraw模块（AI绘画）支持局部重绘(Inpainting)，但OmniComic模块的阶段4
（分镜生图）不支持局部重绘。部分文档描述模糊，需统一明确。

裁定结果：

模块                  功能              策略
OmniDraw (AI绘画)     局部重绘          支持 — 通过 POST /api/v1/paint/inpaint 端点提供遮罩区域修复
OmniComic (漫剧创作)  分镜图重绘        不支持局部重绘 — 分镜图不满意时须整图重新生成，IP-Adapter保证风格统一

设计理由：分镜图作为叙事连续性帧，局部修改可能导致与前后帧不一致。
整图重新生成配合IP-Adapter风格约束，可保证分镜序列的视觉连贯性。

14.4.1 过渡时长

--transition-fast: 150ms ease-in-out     // 按钮hover、图标变化
--transition-normal: 250ms ease-in-out   // 面板展开/折叠、下拉菜单
--transition-slow: 400ms ease-in-out     // 路由切换、大面板过渡

14.4.2 关键动画

- 淡入淡出（fadeIn/fadeOut）：opacity 0→1，250ms
- 缩放淡入（scaleIn）：scale(0.9)→1 + opacity 0→1，250ms（弹窗）
- 从上滑入（slideInDown）：translateY(-20px)→0 + opacity 0→1，300ms（通知）
- 从右滑入（slideInRight）：translateX(20px)→0 + opacity 0→1，300ms（Toast）
- 从下滑入（slideInUp）：translateY(20px)→0 + opacity 0→1，300ms（路由切换）
- 旋转（spin）：rotate(0deg)→360deg，1s linear infinite（Loading 图标）
- 脉冲（pulse）：scale(1)→1.05→1，2s ease-in-out infinite（通知红点）
- 抖动（shake）：translateX(0)→-10px→10px→-10px→0，400ms（错误提示）

14.4.3 动画工具类

.fade-enter-active, .fade-leave-active { transition: opacity 0.25s ease }
.fade-enter-from, .fade-leave-to { opacity: 0 }
.slide-up-enter-active { transition: all 0.3s ease-out }
.slide-up-enter-from { opacity: 0; transform: translateY(20px) }

结构：遮罩层 + 对话框容器（标题 + 内容 + 底部按钮）
功能：
  - 确认对话框（标题 + 消息 + 确认/取消按钮）
  - 自定义内容对话框
  - 全屏对话框
  - 可拖拽移动
  - Esc 关闭
动画：缩放 0.9→1 + 淡入，250ms。
样式：遮罩 rgba(0,0,0,0.6)，对话框背景 --color-bg-secondary，圆角 16px，阴影 --shadow-2xl。

15.3.2 抽屉（OmniDrawer）

方向：从右侧/左侧/顶部/底部滑出
功能：
  - 可拖拽调整宽度/高度
  - Esc 关闭
  - 点击遮罩关闭
样式：背景 --color-bg-secondary，阴影 --shadow-xl。

15.3.3 消息提示（OmniToast）

位置：右上角（默认）/ 顶部居中 / 底部居中
类型：
  - Success：绿色左条 + CheckCircle 图标
  - Warning：黄色左条 + AlertTriangle 图标
  - Error：红色左条 + XCircle 图标
  - Info：蓝色左条 + Info 图标
功能：
  - 自动关闭（3秒/5秒/不关闭）
  - 手动关闭（X 按钮）
  - 操作按钮（如"撤销"）
动画：从右侧滑入 + 淡入，300ms。

15.3.4 消息框（OmniMessageBox）

功能：
  - Alert：标题 + 消息 + 确认按钮
  - Confirm：标题 + 消息 + 确认/取消按钮
  - Prompt：标题 + 消息 + 输入框 + 确认/取消按钮
  - 自定义按钮文字
样式：模态对话框，宽度 420px。

15.3.5 通知（OmniNotification）

位置：右上角，向下堆叠
功能：
  - 标题 + 消息 + 时间戳
  - 关闭按钮
  - 点击跳转
  - 类型标识（左条颜色）
  - 最多显示5条，超出自动关闭最早的

15.3.6 加载指示器（OmniLoading）

类型：
  - Spinner：旋转图标（16/20/24px）
  - Dots：三个跳动圆点
  - Skeleton：骨架屏（卡片/文本/圆形）
  - Progress：进度条（线性/环形）
样式：颜色 --color-primary。

15.3.7 空状态（OmniEmpty）

结构：图标（48px）+ 标题（16px）+ 描述（14px）+ 操作按钮（可选）
样式：居中显示，文字颜色 --color-text-tertiary。

15.3.8 骨架屏（OmniSkeleton）

类型：
  - 文本骨架（多行矩形）
  - 卡片骨架（标题+内容+操作区）
  - 头像骨架（圆形）
  - 自定义骨架
样式：背景渐变动画（shimmer效果）。

15.4 数据展示组件（DataComponents）

15.4.1 统计卡片（OmniStatistic）

结构：标题（12px）+ 数值（32px粗体）+ 趋势指示（箭头+百分比）
功能：
  - 趋势：上升（绿色↑）/ 下降（红色↓）
  - 可配置前缀/后缀
  - 可配置数值格式化

15.4.2 进度条（OmniProgress）

类型：
  - 线性进度条（高度 6px/8px/12px）
  - 环形进度条（直径 60/80/120px）
功能：
  - 显示百分比
  - 自定义颜色
  - 分段进度
样式：轨道 --color-bg-tertiary，已完成 --color-primary。

15.4.3 图表（OmniChart）

基于 ECharts 封装。
类型：
  - 折线图（训练Loss曲线）
  - 柱状图（资源占用）
  - 饼图（显存分配）
  - 仪表盘（GPU使用率）
  - 热力图（行为学习统计）
功能：
  - 实时数据更新
  - 主题适配（深色/亮色）
  - 自定义Tooltip
  - 导出图片

15.4.4 时间线（OmniTimeline）

结构：垂直时间轴 + 节点 + 内容卡片
功能：
  - 自定义节点图标
  - 自定义内容
  - 加载更多
样式：节点 12px 圆形，连线 2px --color-border。

15.4.5 树形控件（OmniTree）

功能：
  - 展开/折叠
  - 复选框选择
  - 拖拽排序
  - 搜索过滤
  - 虚拟滚动
  - 右键菜单
样式：每项高度 28px，缩进 16px/级。

15.4.6 虚拟列表（OmniVirtualList）

基于 @tanstack/vue-virtual 封装。
功能：
  - 万级数据流畅滚动
  - 动态高度
  - 滚动到指定位置
  - 滚动事件监听
性能：10k条数据滚动 FPS>55。

16.4 弹窗动画规范

- 模态弹窗：缩放 0.9→1 + 淡入，250ms ease-out；关闭时反向 200ms
- 抽屉：从侧边滑入，300ms ease-out；关闭时滑出 250ms
- Toast：从右侧滑入 + 淡入，300ms；消失时淡出 + 右移 200ms
- 通知：从顶部滑入 + 淡入，300ms；消失时淡出 200ms
- 灯箱：背景变黑 + 图片放大，300ms；关闭时反向 250ms

16.5 确认弹窗规范

危险操作（删除/清空/覆盖）必须使用确认弹窗：
- 标题：操作描述（如"确定删除此项目？"）
- 内容：影响说明（如"删除后无法恢复，关联的所有资产和分镜将一并删除"）
- 按钮：取消（灰色）| 确认（红色）
- 高危操作：要求输入确认文本（如输入"DELETE"或项目名称）
- 确认按钮在输入正确文本前禁用

16.6 生成记录系统弹窗

位置：各模块顶部的"生成记录"按钮。
弹窗尺寸：宽度 800px，最大高度 600px。
内容：
  - 6个Tab标签横向排列可滚动：
    * 角色图 | 场景图 | 道具图 | 分镜图 | 导演台截图 | 视频
  - 每个Tab下显示对应类型的生成记录网格：
    * 缩略图网格（每行4~6个，120x120px）
    * 每项：缩略图 + 时间戳 + 来源模块标签
    * hover显示操作按钮：预览/下载/删除
    * 支持多选批量删除
  - 记录永久保留，不自动清理
  - 支持按日期范围筛选
  - 支持按项目筛选
  - 支持搜索

第十八章 状态管理（Pinia）
================================================================================

18.1 全局应用状态（useAppStore）

状态字段：
  - currentModule: string             # 当前激活模块（chat/paint/storyboard/learning/models/style/settings）
  - sidebarCollapsed: boolean         # 侧边栏折叠状态
  - rightPanelCollapsed: boolean      # 右侧面板折叠状态
  - rightPanelWidth: number           # 右侧面板宽度（280~500px）
  - theme: 'dark' | 'light'           # 当前主题
  - systemStatus: SystemStatus        # 系统状态（CPU/GPU/VRAM/RAM等）
  - websocketConnected: boolean       # WebSocket连接状态
  - activeTabs: TabInfo[]             # 已打开的标签页列表
  - currentTabId: string              # 当前激活标签页ID

Actions：
  - setModule(module: string)         # 切换模块
  - toggleSidebar()                   # 切换侧边栏
  - toggleRightPanel()                # 切换右侧面板
  - setRightPanelWidth(width: number) # 设置右侧面板宽度
  - toggleTheme()                     # 切换主题
  - updateSystemStatus(status)        # 更新系统状态
  - addTab(tab: TabInfo)              # 添加标签页
  - closeTab(tabId: string)           # 关闭标签页
  - switchTab(tabId: string)          # 切换标签页

18.2 对话状态（useChatStore）

状态字段：
  - sessions: ChatSession[]           # 会话列表
  - currentSessionId: string          # 当前会话ID
  - messages: ChatMessage[]           # 当前会话消息列表
  - isGenerating: boolean             # 是否正在生成
  - streamingMessage: string          # 流式消息内容
  - settings: ChatSettings            # 对话参数（Temperature/Top-P/MaxTokens等）

18.3 绘画状态（usePaintStore）

状态字段：
  - currentTab: 'txt2img' | 'img2img' | 'inpaint' | 'upscale'  # 当前标签页
  - params: PaintParams               # 绘画参数（Prompt/Steps/CFG等）
  - controlNet: ControlNetConfig      # ControlNet配置
  - ipAdapter: IPAdapterConfig        # IP-Adapter配置
  - history: PaintHistory[]           # 历史记录
  - batchQueue: BatchTask[]           # 批量生成队列
  - isGenerating: boolean             # 是否正在生成

18.4 漫剧状态（useStoryboardStore）

状态字段：
  - projects: Project[]               # 项目列表
  - currentProjectId: string          # 当前项目ID
  - currentStage: number              # 当前阶段（1~6）
  - storyboards: Storyboard[]         # 分镜列表
  - selectedStoryboardId: string      # 选中分镜ID
  - assets: AssetPool                 # 资产池（角色/场景/道具）
  - characters: Character[]           # 角色列表
  - directorState: DirectorState      # 导演台状态
  - videoSettings: VideoSettings      # 视频生成参数

20.1 Vue3 组件规范

20.1.1 组件命名

- 组件名使用 PascalCase：OmniButton.vue
- 组件文件名与组件名一致
- 全局注册组件以 Omni 前缀命名
- 页面级组件以 Page 后缀命名：ChatPage.vue

20.1.2 组件结构（Composition API + <script setup>）

标准组件结构：
  <template>
    <!-- HTML模板 -->
  </template>

  <script setup lang="ts">
  // 1. 导入
  import { ref, computed, onMounted } from 'vue'
  import { useAppStore } from '@/stores/useAppStore'

  // 2. Props & Emits
  interface Props {
    modelValue: string
    label?: string
    disabled?: boolean
  }
  const props = withDefaults(defineProps<Props>(), {
    label: '',
    disabled: false
  })
  const emit = defineEmits<{
    'update:modelValue': [value: string]
    change: [value: string]
  }>()

  // 3. 响应式状态
  const inputValue = ref(props.modelValue)

  // 4. 计算属性
  const displayLabel = computed(() => props.label || '默认标签')

  // 5. 方法
  const handleChange = (e: Event) => {
    const value = (e.target as HTMLInputElement).value
    inputValue.value = value
    emit('update:modelValue', value)
    emit('change', value)
  }

  // 6. 生命周期
  onMounted(() => {
    // 初始化逻辑
  })
  </script>

  <style scoped>
  /* 组件样式，使用 CSS 变量 */
  </style>

20.1.3 Props 规范

- 使用 TypeScript interface 定义 Props
- 必填 Props 不加 ?，可选 Props 加 ?
- 使用 withDefaults 提供默认值
- 避免 any 类型，使用具体类型

20.1.4 事件规范

- 使用 defineEmits 泛型定义事件
- 事件名使用 kebab-case
- v-model 使用 update:modelValue 标准事件

20.2 TypeScript 规范

- 严格模式：strict: true
- 禁止 any 类型（eslint 报错），必须使用 unknown 或具体类型
- 接口命名使用 PascalCase，不加 I 前缀
- 枚举命名使用 PascalCase
- 类型别名使用 PascalCase
- 函数返回类型必须显式标注

20.3 CSS 规范

- 优先使用 Tailwind CSS 工具类
- 复杂样式使用 <style scoped> + CSS 变量
- 禁止硬编码颜色值，必须使用 var(--color-*) 变量
- 禁止 !important（特殊情况除外，需注释说明）
- 类名使用 kebab-case
- Scoped 样式使用 :deep() 穿透子组件

20.4 文件命名规范

- 组件文件：PascalCase（OmniButton.vue）
- 页面文件：PascalCase + Page 后缀（ChatPage.vue）
- 工具文件：camelCase（format.ts）
- 类型文件：camelCase（api.ts）
- 样式文件：kebab-case（variables.css）
- 常量文件：camelCase（constants.ts）

20.5 代码格式化

- 使用 ESLint + Prettier
- 缩进：2 空格
- 引号：单引号
- 分号：结尾加分号
- 最大行宽：120 字符
- 尾逗号：es5（数组和对象最后一项加逗号）

20.6 Git 提交规范

格式：type(scope): description

类型：
  - feat: 新功能
  - fix: 修复Bug
  - refactor: 重构
  - style: 样式调整（不影响功能）
  - docs: 文档更新
  - test: 测试相关
  - chore: 构建/工具/依赖更新
  - perf: 性能优化

示例：
  feat(chat): 添加流式打字机效果
  fix(director): 修复3D视口内存泄漏
  refactor(models): 重构模型加载逻辑
